# 数据与隐私

所有数据都保存在**本机的用户数据目录**里，不上传任何服务器。

```
{root}/plugins/           文档渲染插件：*.js + enabled.json（启用清单）。**代码**，与用户无关，
│                         跟着数据目录走；默认不加载，见 rendering.md
{root}/runcache.json      代码块的伪编译产物 + 「无输出」标记：键都是「语言 + 代码内容」的指纹，
│                         前者是编译好的 JS，后者是导师判定「这段没什么可跑的」的结论。
│                         删掉只是下次要重编，见 code-run.md
{root}/users/{uid}/
├─ user.yaml            用户信息（画像）
├─ setting.yaml         用户配置：外观（主题、字号、两栏宽度与左右位置、教学模式）+ 快捷键改键
│                       + AI 提供商与模型 + 语音开关 + agent（压缩阈值等）
├─ state.json           学习区的界面状态（当前目标 / 节点 / 对话 / 正在看哪份文档 / 没保存的暂存）
│                       + 番茄钟（它是用户级的：今天专注了几组与哪门课无关）
├─ web/                 Agent 抓回来的网页：{uuid}.md 是正文、{uuid}.json 是来源/标题/大纲
└─ docs/
   └─ {目标}/
      ├─ {目标}.md              根节点的教学文档
      ├─ {目标}.notes/          根节点的笔记：**一份一个文件**，名字就是文件名（{名字}.md）
      │                         空笔记不落盘；名字与时间记在 meta.json 的 notes 里（顺序才稳定）
      ├─ {目标}.meta.json       根节点元数据 + 目标本身
      ├─ chat.json              **目标的**对话（上下文是目标级的，不按节点分）
      ├─ tmp.json               Agent 的临时变量（可缺省）
      ├─ reading.json           这个目标的有效阅读账（会话、每节点读到哪、按学习日的汇总）
      ├─ checkin.json           这个目标的打卡账（每个学习日的尝试与结果）——没记录就不写这两个文件
      ├─ static/                **目标级资源库**：贴进来的图、PDF、附件（{uuid}.{ext}，能直接双击打开）
      │                         附件在**消息发出去那一刻**才转存到这里（贴进输入框只是草稿）
      │  └─ manifest.json       资源清单：uuid / 名称 / 后缀 / 类型 / 描述 / 上传·修改日期 / 大小 / 内容指纹
      ├─ images/                旧版提问图片目录（迁移前的数据，只读保留；新附件都进 static/）
      └─ {子节点}/
         ├─ {子节点}.md
         ├─ {子节点}.notes/{名字}.md
         └─ {子节点}.meta.json
```

## 几条约定

- **目录名就是标题**；`.md` 是干净的正文（不含任何元数据语法），**可以脱离应用直接读、改、备份**。
- **一个节点一份教学文档**（`{节点}.md`）加**任意多份笔记**（`{节点}.notes/{名字}.md`，
  空着就不建文件）；笔记**改名 = 改文件名**（界面上的名字与磁盘上的名字是同一个，因此非法字符
  在命名那一刻就被换掉），关掉 / 删掉一份笔记时，指着它的页签也一并处理——不会留下一个点开是
  空白的幽灵页签。
- **结构化字段**（学习状态的自评 / 掌握度 / 错误记忆 / 检验记录、注解、依赖边、考试记录）
  在同目录的 `.meta.json` 里；**对话在目标目录的 `chat.json`** 里。没评估过的节点不写 `learning`
  这一项——「没测过」与「测出来是空的」在文件里也是两回事。
- **资源库里的文件按 uuid 命名**（改名只动清单，不动文件），文档里用
  `![说明](moji:static/<uuid>)` 引用；Agent 通过 `res.*` 这一组 api 管理它们（清单 / 读 / 改 / 删 /
  引用扫描），读图时图片走图像通道、不返回 base64。

## 旧布局读到即迁移

单文档时代的正文折进教学文档，节点目录里那份 `{节点}.笔记.md` 并成一份名为「笔记」的笔记
（写回时老文件由差异比对删掉），散在各节点目录的 `chat.json` 按节点所属目标并到那一份。

界面状态（当前目标 / 节点 / 对话、**文档区的分组与分割**、打开的页签、本地文件列表、**暂存区**）
在 `state.json` 里，与学习数据分开存：文档区那一份是 `docArea`（布局树 + 每一格的页签，
见 `src/learn/groups.ts`），**旧版那种平铺的 `tabs` / `activeTab` 读回来会自动折成单组**——
升级之后看到的还是原来那排页签；页签指向的东西已经不在了时，读回来会被丢掉——一个指向空处的页签
点开只会让人以为「文件坏了」；暂存区（改了没保存的正文，键是页签 id，见 `src/learn/drafts.ts`）
同理，指向的节点没了就不认它了。

## `{root}` 在哪

`{root}` 属于**全局设置**（跟这台机器绑定，不属于任何用户），默认是 Electron 的 `userData`
（Windows 下为 `%APPDATA%\unyra`；v0.4.9 前是 `%APPDATA%\moji-notes`，升级后第一次启动会把整份目录
自动搬过来），与窗口尺寸、会话一样放在那里；关窗行为也记在同一份
`global.yaml` 里。可在**设置 → 存储**改到任意位置：**换目录即换一整套数据**，
原目录的文件不会被移动或删除。

## 会离开这台机器的请求

只有两类，都由**主进程**发出：

| 请求 | 去哪 | 带上什么 |
| --- | --- | --- |
| 模型请求 | 你配置的提供商（默认 `api.deepseek.com`） | 对话上下文、文档内容、附件（图片按模态） |
| 更新检查 | 公开的发布仓库（GitHub Releases） | 什么都不带，匿名 HTTPS |
| 抓网页（`api.web.webFetch`） | 模型给出的那个网址 | 只读、不带 cookie 与本机凭据 |

- AI 功能需在设置中自行填入所选提供商的 API Key（**同样只存在本机**）。请求不经过任何中间服务；
- 主进程**只转发白名单内的主机**，白名单来自内置预设与你实际配置过的地址，白名单外一律 403
  （见 [architecture.md](architecture.md#为什么-ai-请求要经主进程)）；
- 抓网页有三条硬规则写在 `electron/web-core.ts` 里、用例钉着：**只读、有上限（4MB / 20 秒）、
  本机与内网地址一律拒绝**——Agent 是模型写的代码，不能给它一个读本机服务的口子；
- **代码块运行沙箱联网要每次点一次头**：沙箱里没有「不经过用户同意」的网络，`fetch` 先举手，
  同意之后本次运行内不再重复问，真正的请求由主进程代发（见 [code-run.md](code-run.md)）；
- 语音识别的**音频不出本机、也不写盘**（见 [shortcuts-and-voice.md](shortcuts-and-voice.md)）。
