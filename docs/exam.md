# 考试：试卷、考试窗口与记录

> 试卷是**两层**的：一份**试卷**（题目、类型、难度、时限）可以有**很多次考试**。
> 同一份卷子反复考不必复制题目，历次成绩天然是一组，每次考试的作答与记录也不会互相覆盖。

## 一次考试的完整路径

1. **出卷**：资源管理器里在试卷那一行右键 →「新增」，或让它触发内置工作流「出卷」。
   它不先问你类型难度——那是导师在对话里用一张表单问的（留空＝它按掌握度与错误历史替你定）；
   时限也由它按题量与难度估（代码强制下限**每题 2 分钟**，随堂小测不限时）。
2. **开考**：资源管理器里在试卷那一行**右键 → 考试**（正在考另一份时那一项变成「回到考试」），
   点开一个**独立的 Electron 窗口**。
   窗口先给你一屏规矩：**开始考试 / 退出**——**没开始就退出，什么都不会发生**（连一条记录都不建）；
   一旦开始，就只有「交卷」与「放弃」两条路（关窗＝放弃，主进程会先拦下来问一句）。
   开始后窗口**自动全屏**，主窗口盖上一层**黑遮罩**（遮罩上只有一颗「回到考试窗口」）——
   考试期间翻文档就是作弊，遮罩挡的就是这个。
3. **作答**：卷面是**单栏 768px**，一路往下读（不分栏、不翻页——试过动态分列，
   实际读起来不如窄栏舒服：一行太长眼睛要横扫，而题干本来就短）。题目与选项都不画卡片；
   **题干与序号同一行**：「1. （单选题）题干……（2 分）」，比三行抬头省两行，扫卷更快。
   选项是**弹性布局**：短的并排（「正确 / 错误」一行看完），长的自己占满一行再换行。
   底部浮着一条**水平题号条**（不占版面、可收起展开）：答过的实心、没答的空心，点一下跳过去。
4. **收尾**：
   - **交卷**：算分（没答的题记 0 分）。交卷之后主窗口会被叫回前台，遮罩撤掉、你直接看判分。
     接着导师跑「阅卷」：判分 + 写错题讲解。讲解一写完，**那一次的试卷副本页签会自动打开**——
     用户等的就是错题解析，让他再去列表里翻出那一次，等于把刚做好的东西又藏起来。
     平时要找它：左侧资源管理器里展开该节点的试卷，点「考试记录」那一条即开（右键还有开考 / 判分 / 删除）。
   - **放弃**：**直接记 0 分，不判分、也不写错题讲解**——这是用户的选择，导师不该补。
   - **到点**：开考前可以选「到点强制交卷」；关掉它可以继续作答，**超时多久、哪几笔是超时答的**
     都会被记下来（不会因此判作弊，但它是一条学习信号）。

## 记录下来的东西都是给 AI 看的

`learn/examRecords.ts`，纯函数、有单测：

| 记录 | 怎么记 | 用来判断什么 |
| --- | --- | --- |
| 输入顺序 | 每次落定一条（题号 + 答案 + 时间戳）；**同一题 5 秒内的连续输入合并成一条**，超过 5 秒算一次「更改」追加一条 | 先答哪题、哪题改过、在哪题上犹豫 |
| 单题耗时 | **按答案顺序推**：这次落定答案的时间戳 − 上一次落定答案的时间戳（第一次从开考算），切出去的那段扣掉 | 卡在哪、哪题是「不会」而不是「没时间」 |
| 切屏 | 每次失焦一条 `{起始时间戳, 时长}` | 是否频繁离开考试窗口 |
| 超时 | 超时总时长 + 每一笔超时作答的标记 | 是熟练度不够还是题目太长 |

刻意**没有**单独存一份「答案变动记录」：输入流水本身就是它，两份数据迟早对不上——
答案与流水由同一次写入（`recordInput`）一起维护。

单题耗时也**不需要界面配合**：早先试过「屏幕上一条计时区、把当前题滚进区里才走表」，
那既要用户配合、又只在他刚好把题滚进去时才记账；改成按相邻两次落定的时间戳推之后，
他怎么翻、怎么跳、怎么改答案都不影响记账。

## 判分与错题讲解是同一套工作流的两步

内置工作流「阅卷」，交卷后自动跑：

1. **判分**：`api.exam.grade`——客观题以系统的严格判分为准，主观题采信导师，每道错题都要给 comment。
2. **讲解**：`api.exam.explain`——先看 `api.exam.read()` 回来的 **history**（历次考试的 `weak`：
   那次考错的题），**反复出现的同一个错法才是薄弱项**，然后写一份 Markdown 讲解。
   它落在**那一次考试**上，显示在只读的**试卷副本页签**里（点历史里的一条就打开它：
   卷子原件 + 你的作答 + 判分 + 错题讲解 + 这场考试的记录）。副本里**对错用固定的红绿**、
   不跟主题走（主题的强调色在樱花粉主题下是粉的，用它表示「错了」会看着像表扬）；
   错题讲解那一大段**默认折叠**，标题行写着字数，想细看再点开。

## 删除分两档

没考过的一次确认就删；考过的先弹一屏**逐条列出会连带删掉什么**
（几次考试、几份判分与讲解、试卷本身），确认之后再问一次。破坏性动作的价格要一次说清。

这条判据在 `learn/exam.ts` 的 `examDeleteBlock` 里，是纯函数、有测试钉着——
「不许删用户的东西」不该指望模型自觉。
