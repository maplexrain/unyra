# 代码块的伪编译与运行

> 文档里的代码块为什么能「跑」起来：一段转译工作流 + 一个一次性运行沙箱。
> 高亮（那是纯展示）见 [rendering.md](rendering.md)。

鼠标经过文档里的代码块，右上角浮出一个竖排菜单：**复制 / 编译 / 运行**。
运行默认是灰的，**先编译成功**才亮得起来。

```text
代码块 ──→ 「编译」：请**超级导师**跑内置工作流「伪编译」（把代码、语言与一个 key 交出去）
        ──→ 第零步：导师先判这段代码有没有输出
              ├─ 没有（只有类型 / 接口 / 函数 / 类定义）
              │    ──→ 立刻停止编译，api.code.silent({ key, reason }) 交货
              │    ──→ 那一块从此只有「复制」，编译与运行不再出现（落盘，重启也还在）
              └─ 有 ──→ 读这篇文档补上下文；读不到、或读到也不够就模拟一份合理的假上下文
                        ──→ 转译成自包含的 JS，api.code.save({ key, js, note }) 交货
                        ──→ 宿主按 key 认领 → 落盘（{root}/runcache.json）→ 「运行」亮起来
        ──→ 「运行」：在一次性 Worker 沙箱里执行，输出贴在代码块下面
```

## 编译是导师的活，不是菜单的活

菜单不自己发模型请求，只把代码交给一条**工作流**（指令见 `learn/workflows` 的「伪编译」）——
于是它跑在对话里，用的是导师手上的全部上下文：这篇文档、这个学习者在学什么、前面讲过什么。
**说明与产物都在对话那一侧**，代码块下面那一栏**只放运行输出**。

**它不抢主位**：点「编译」不会把对话栏拽到眼前（内置表里它是 `prep: 'show'`：只响一声铃）。
用户此刻正盯着自己点的那一块，回执也画在那儿——转圈 → 「运行」亮起（或被标成「无输出」并写明理由），
导师那段说明在对话里等着他什么时候去看。**会切主位的只有问询类工作流**
（`prep: 'ask'`：第一步是一张压在输入框上方的表单，不回答就走不下去；见 `workflowPrep`）。

## 残缺片段

文档里贴的往往是半截代码。导师会自己去读**这段代码所在的那篇文档**（api.doc.read / readRange / find）
把缺的定义补齐；文档里也找不到的，就模拟一份合理的假上下文（假数据、假函数），并把假设写进 note
显示出来——绝不回一句「无法编译」。

## 为什么 key 由宿主给

产物要挂回**那一个**代码块上。代码原文由宿主记着（它就是从那一块取走的），模型只交 js 与说明——
几千行代码让模型回抄一遍，错一个空格指纹就对不上。

**产物按内容寻址**：键是「语言 + 代码内容」的指纹（见 lib/codeArtifacts）。所以重启后产物还在
（按钮直接是「重新编译」的样子），而代码一改，指纹就对不上——按钮自己变回「编译」，
不需要谁去清状态。

## 运行沙箱里只有两件事

打印与联网。没有 DOM，拿不到 `window.mojiNative`，localStorage / indexedDB / caches
在 Worker 里被逐个收走；死循环由宿主 terminate 收掉（默认 15 秒）。

**联网每次运行问一次**：沙箱里没有「不经过用户同意」的网络——`fetch` 先举手，宿主弹出确认框，
同意之后本次运行内不再重复问；真正的请求由**主进程**代发（渲染层的 CSP 连不上外网，
见 [architecture.md](architecture.md#为什么-ai-请求要经主进程)）。不点头，代码拿到的是一句拒绝。

## 没有输出的块在第一步就被拦下

只有定义（类型 / 接口 / 函数 / 类）的代码块，导师一眼就看得出「转译出来也没有任何东西可看」，
于是它**不写 JS**，改调 `api.code.silent` 交货；那一块从此只有「复制」和一枚「无输出」标签
（悬停写着导师的理由），编译与运行不再出现。

这个判定**由导师做，不在本地扫**：判错的方向是不对称的——误判一次，那块代码就再也点不了编译了。
标记与产物一样按「语言 + 代码内容」寻址并落盘：代码一改，它就失效，那块自动变回可编译。

## 等待与订阅

「编译」要等导师交货，那颗按钮会一直转圈（上限三分钟）；产物一到就自己亮起来——
它订阅的是产物表（见 lib/codeArtifacts 的 `subscribeArtifacts`），不是某个 promise。

它同样是**内置插件**（设置 → 插件 → Markdown 文档插件 → 代码块编译运行），可以整个关掉。

## 代码分布

| 文件 | 是什么 |
| --- | --- |
| `src/run/RunnerRuntime.js` | 跑产物的那个沙箱（纯 JS，被当作字符串塞进 Blob Worker，与 agent 的 `sandboxRuntime.js` 同一套路数） |
| `src/lib/codeRun.ts` | 宿主这一半：起停、输出、联网确认 |
| `src/lib/codeArtifacts.ts` | 产物：指纹、内存表、待编译登记与订阅 |
| `src/lib/docHost.ts` | 「谁来跑工作流」那根线（学习区注册） |
| `src/learn/workflows.ts` · `src/learn/agentOps.ts` | 转译本身是内置工作流「伪编译」+ `api.code.save` / `code.silent` |
| `src/lib/codeBlockMenu.ts` | 代码块上那个菜单 |
| `tests/codeRun.test.ts` | 用一个 vm 造的假全局把运行时**真的执行一遍**——那份 .js 是字符串，语法错在构建期看不出来 |
