归一 Unyra v0.7.2 —— 全链路性能优化与实时性能监控看板、系统级毫秒截图与贴图工具箱、WebSearch 权威防幻觉与主观认知双轨协同、大纲 Port 嵌套拆分与系列稳定性体验升级。

## 全链路性能优化与实时性能监控

- **VFS 帧级微批处理调度器**：针对 AI 批量创建大纲、目标节点、连线与讲义正文时的密集写入，引入 16ms / rAF 微批处理聚合机制，将短时间内的数十次文件变更合并为单次 React 调度，大幅消除渲染风暴（消峰率达 85%~90%）。
- **结构画布视口裁剪 (Viewport Culling)**：为知识结构画布引入动态视口包围盒裁剪与 $O(1)$ 拓扑索引，远离视口的节点仅保留轻量占位，跳过数千个复杂子 DOM 节点与冗余计算，保证 50+ 节点大型图谱下平移缩放稳定 60 FPS；同时大幅简化 Minimap 绘制负荷。
- **阅读心跳防抖与消除强制重排 (Forced Reflow)**：优化阅读采集器 1 秒心跳机制，增加几何位置读数缓存，在无滚动和静默阅读期复用布局计算，彻底消除每秒触发 `getBoundingClientRect` 造成的页面微顿挫。
- **VFS 缓存有界化与常驻页签释放**：为 VFS 原始文本缓存施加 300 条 LRU 封顶，防止长时间运行下老生代堆内存无界膨胀；提供常驻页签一键释放接口，快速回收后台隐藏 DOM 节点。
- **全新「设置 → 性能」实时监控面板**：
  - **健康度实时仪表**：实时监测帧率（FPS）、JS 堆内存（MB 与使用率）、活跃 DOM 节点总数及连续运行时间；
  - **卡顿诱因深度监控**：实时呈现 VFS 批处理消峰吸收率、画布视口裁剪与离屏数、常驻页签数量、缓存池占用；
  - **性能急救工具箱**：支持「立即释放后台常驻页签」、「深度清理内存缓存池」与「软重载渲染页面」。

## 系统级硬件截图与多贴图工具箱

- **毫秒级全屏硬件截图**：集成原生 BitBlt 高速捕获引擎，彻底杜绝系统黑屏与白边，实现毫秒级高清全屏截取。
- **全局快捷键与窗口吸附重做**：
  - 支持 Windows 系统级双击反引号 (\`) 瞬时唤起截图；
  - 重做智能窗口检测算法，引入真实视口与遮挡排他性判定，仅在窗口真正可视时才自动吸附；
  - 支持右键点击快速退出截图、选取后双击快速复制到剪贴板并退出；
  - 选取尺寸测量标注优化至选框左上角显示。
- **独立置顶贴图窗口体验**：
  - 截图直接固定至独立无边框贴图窗口，支持滚轮调节尺寸、平滑拖拽与右键关闭；
  - 修复多贴图窗口切换与固定时的闪烁问题，实现纯净无缝切换。

## WebSearch 权威防幻觉与主观认知双轨协同

- **权威防幻觉与背书保障 (Fact Grounding & Authority)**：纠正生成文档和大纲时跳过联网的偏差，明确 WebSearch 必须作为消除模型幻觉、核准术语边界、为知识交付物提供权威参考源背书的核心支柱。
- **主观心智阶梯规划 (拒绝机械照搬)**：坚决维护导师自身教育学逻辑与认知阶梯制定权，阶段目标的划分与深度推导由导师主观深度设计，严禁把搜索到的网页目录机械复制为目标项。
- **权威引证规范与交付登记**：生成的教学讲义末尾必须规范附带「## 📚 参考资料与权威来源」网页 Chip，并在收尾时通过 `api.delivery.submit({ sources })` 登记，让学习者直观感受严谨有据的知识脉络。

## 大纲嵌套拆分与 Agent 能动性增强

- **大纲挂接大纲 Port 生成总览**：修复大纲节点挂在大纲目标项 port 下点击「生成总览」无响应的 Bug，完整打通大纲树的逐层细化与嵌套分解体系。
- **两种连接模式深度融入 Agent 认知**：
  - 文档连接大纲 port：思想为「讲解这个目标的内容」（落地为讲义文档）；
  - 大纲连接大纲 port：思想为「进一步拆分这个目标」（挂接子大纲分层细化阶段目标）。
- **根据学习状态提议修改文档 (Ask 授权机制)**：允许 Agent 根据学习者做题错题、盲点等反馈主动提议完善文档，但必须通过 `api.ask` 征得学习者明确授权后方可执行修改。
- **固定聊天 Tab 占位独立化**：优化固定聊天面板空占位引导，清晰区分学术导师与自由对话定位。
