归一 Unyra v0.7.7 —— 节点宇宙大纲树视图模式（思维导图）、资源管理器性能极致优化、文件节点与外部拖拽落盘、目标数据扁平解耦与迁移、大纲项内联极速输入。

## 节点宇宙：大纲树视图模式（思维导图）

- **双视图自由切换（拓扑图 / 大纲树）**：
  - 节点宇宙右上角及底部工具栏新增视图切换胶囊，支持在自由连线拓扑图与横向大纲树视图（思维导图）之间自由切换；
  - 用户的视图偏好自动持久化落盘，并在主工作区与 F1 全局浮层之间保持无缝同步。
- **纯粹的大纲沉浸浏览与分支折叠**：
  - 大纲树模式采用横向思维导图布局，下游各级子知识点支持自由展开与收起；
  - 全面开启只读保护（禁用误拖拽、改色、右键连线菜单与快捷键），点击卡片标题或附属文档直接打开对应页签，专注结构复盘与查阅。

## 资源管理器：侧栏与节点树性能极速优化

- **消除侧栏展开/收起的掉帧与卡顿**：
  - 侧栏重构为常驻双层布局设计，消除收起与展开时销毁并重建数百个 DOM 节点的 Long Task 峰值；
  - 展开与折叠过渡期间自动锁定内部定宽容器，杜绝 300ms 动画期间的全量逐帧回流（Reflow），帧率大幅提升。
- **节点树懒加载与渲染隔离**：
  - 子树初次展开采用懒渲染挂载策略，未展开内容零 DOM 占用；
  - 引入 CSS `contain: paint` 渲染隔离，超大项目在海量节点下展开折叠依旧轻快敏捷。

## 节点宇宙：文件节点与外部文件直接拖拽

- **全新文件节点支持**：
  - 新增「文件节点」类型，支持绑定本地文件与外部网页链接；
  - 上下游支持与文档节点、笔记节点、超级文档、考试节点及大纲节点自由双向连线，点击卡片标题自动以对应页签呈现。
- **外部文件拖入直接落盘**：
  - 支持将外部文件（PDF、图片、音视频、代码或文档等）直接拖拽至节点宇宙画布任意位置，自动拷贝至 `docs/{目录}/files` 隔离存储，并在鼠标落点处原地创建文件节点；
  - 删除文件节点时自动执行级联物理清理，避免无用文件堆积占用磁盘空间。
- **拖拽体验修复与精准类型过滤**：
  - 修复外部非 `.unr` 文件拖入应用时误触发导入遮罩并卡死的问题，精准过滤拖拽文件类型。

## 目标数据解耦与平滑迁移

- **同级扁平数据存储架构**：
  - 重构大纲目标节点与子级数据的存储模型，消除父子节点强耦合物理层级，转为同级解耦架构，随时随地自由拆分与重新组合；
- **设置 - 一键数据迁移工具**：
  - 在「设置 - 数据迁移」中内置平滑迁移脚本，自动扫描并升级旧版本层级数据，确保老项目无缝兼容。

## 交互细节与画布体验优化

- **大纲项内联创建与编辑**：
  - 目标项创建与改名不再弹出外部提示弹窗，直接在列表内化为内联输入框，Enter 回车即刻提交，不允许误触换行，录入极速流畅；
- **画布放大防模糊与按钮修复**：
  - 优化高倍缩放下的文字抗锯齿与渲染参数，彻底解决节点宇宙放大时文字模糊的问题；
  - 修复画布大纲添加目标项按钮偶发点击失效的问题；
  - 修复画布缩放平移防抖与空教学文档手动撰写。
