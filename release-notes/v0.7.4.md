归一 Unyra v0.7.4 —— Typora 级所见即所得笔记编辑体验、多引擎离线 OCR 插件与 PDF 隐形文字层、PDF 阅读器平滑缩放与渲染修复、马克笔智能反选与引用边框高亮。

## Typora 级所见即所得笔记编辑体验

- **所见即所得排版重构**：
  - 彻底重构笔记编辑交互，告别离散卡片模式，提供全屏沉浸式的 Typora 风格所见即所得 Markdown 编辑体验；
  - 阶梯式标题体系（H1~H4）层次分明，非聚焦行自动隐藏 `#`、粗体、斜体等 Markdown 语法标记，光标触达时精准展开；
  - 水平分割线（`---`）常态下渲染为直角质感的分隔装饰线，光标移入时即时展开源码；
- **原生列表小部件（Widget）重构**：
  - 采用 CodeMirror 原生 `BulletWidget` 与直角可交互 `TaskWidget`，彻底根除 CSS 伪元素与字体尺寸缩放导致的行基线位移与缩进对齐问题；
  - 支持直接鼠标点击勾选/取消任务列表；
- **光标移动稳定性修复**：
  - 根除按上/下方向键光标意外跳跃至文档首行的问题：将所有行级样式由外边距改为内边距，确保 CodeMirror 内部高度图（HeightMap）与 DOM 渲染 1:1 吻合；
  - 清除页面切换过渡残留的 CSS 变换矩阵，避免 Chromium 选区坐标系计算偏差。

## 多引擎离线 OCR 插件与 PDF 隐形文字层

- **多模型/引擎下载与热切换**：
  - 新增 OCR 独立功能插件架构，支持 Windows 原生 OCR 引擎与高精度 PaddleOCR ONNX 深度学习模型等多种引擎方案；
  - 深度支持离线与本地优先运行，模型自动缓存与多源镜像下载；
- **PDF 隐形文字层（Text Layer）贴合**：
  - 自动识别扫描件与图像型 PDF 页面，将识别字符以隐形文字层精确 1:1 映射贴合到原始版面坐标位置；
  - 解决扫描版 PDF 无法原生选中、划词复制与精读标记的痛点；
- **原生阅读感选区高亮**：
  - 文本选中时只呈现高亮选区背景，隐藏文字自身，完美保留原版排版与原汁原味的阅读质感；
- **开箱即用与提示引导**：
  - 未安装 OCR 插件时打开 PDF 顶部弹出友好提醒，支持一键直达安装页。

## PDF 阅读器性能与视口优化

- **消除明暗闪烁与尺寸压缩**：
  - 彻底根除快速滚动 PDF 页面时的重绘白屏与明暗交替闪烁；
  - 修复 PDF 页面在复杂弹性盒（Flexbox）容器中被意外纵向压缩为窄白条及高分屏下的栅格化尺寸失真；
- **平滑缩放体验**：
  - 深度优化 `Ctrl + 滚轮` 缩放响应，增加高频连续滚轮事件平滑防抖捕获；
  - 浏览 PDF 视图时自动隐藏无关浮动工具栏，最大化可视面积。

## 标记（马克笔）与原文引用精读交互

- **独立标记快捷键**：
  - 文档区选中文字后菜单新增「标记」（快捷键 `5`）功能，无需额外输入注解文字即可一键荧光标记；
  - 纯标记状态下自动抑制气泡 Tip 弹窗，视觉纯净；
- **杜绝叠层与智能反选**：
  - 选区与已有标记相交或包含既有标记时，菜单按钮自适应变为「取消标记」，再次标记即一键撤销重叠标记，彻底杜绝多层叠加；
- **原文引用组件视觉增强**：
  - 原文精读引用卡片（Quote）左侧边框加粗并高亮呈现为印章红（`--color-seal`），重点引用段落一目了然。

## 界面交互与动效打磨

- **资源管理器一键折叠**：
  - 资源管理器左上角点击应用 Logo 支持一键收起/展开侧边栏；
- **标签页平滑过渡**：
  - 顶部 Tab 栏切换增设平滑淡入过场动画（`0.18s`），切换更具呼吸感；
- **工具栏视觉规范**：
  - 统一文档区左侧垂直工具栏配色与直角极简设计规范，消除多余彩色干扰。
