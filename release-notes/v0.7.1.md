归一 Unyra v0.7.1 —— 多对话页签与快速新建、任务/聊天模式清晰解耦、出版级教学排版配方升级、新架构学习目标删除修复与系列体验打磨。

## 多对话页签与会话管理

- **支持多对话 Tab 并存**：Agent 区域全面支持同时驻留多个独立的会话 Tab，并在页签栏右上角提供「新建对话」(+) 快捷按钮，点击立即在当前目标页签组下增加全新会话并自动聚焦。
- **历史对话平铺打开**：优化历史记录开启逻辑，从原先在当前 Tab 覆盖式替换，改为在当前目标页签组内额外开启新对话 Tab。
- **重名页签自动消歧序号**：当同一目标下开启多个同名对话时，系统自动感知并标注序号（如「计算机网络 1」「计算机网络 2」），防止用户混淆。
- **页签组级联合理收容**：统一文档区与 Agent 区的页签组收容体系，Agent 区强制保留至少一个对话 Tab；当最后一个对话 Tab 被关闭时，自动平滑联动关闭整个目标页签组。

## 任务模式与聊天模式深度解耦

- **任务模式前置 Chip 标识**：任务模式页签图标前置替换为精致的 `task` 药丸徽章（Chip），告别冗余括号后缀，视觉层级更加轻盈清晰。
- **固定聊天职责边界约束**：优化固定聊天 Agent 的系统引导提示词。若用户尝试让聊天 Agent 执行生成大纲、新建文档等任务，系统将主动拦截并贴心引导用户前往具体任务页签。
- **修复聊天 Agent 文件与图片上传**：修复固定聊天会话中无法上传文件与纯图片附件发送报错的问题，将公共附件规范持久化于目标静态资源区。

## 出版级教学讲义排版规范升级

- **扩充至 12 个出版级精装教学配方**：升级 AI 教学文档生成的视觉排版提示词规范，新增与优化带眉标提示框、双栏概念交锋与正误辨析、时间轴连线步骤链、定理与公式深度拆解、因果推导链、名词术语卡片等高频教学视觉组件。
- **强化微排版层次**：告别单调灰盒子原型，严格遵循纸墨风 Token 规范与自适应深浅色，让 AI 生成的教学讲义具备真正的出版物阅读韵律。

## 学习目标管理与稳定性修复

- **学习目标删除与级联清理**：修复新架构（节点宇宙）下学习目标无法从资源管理器正常删除的缺陷；补齐目标删除时对画布节点、缓存和会话的完整级联清理，并支持删除后的快速撤回恢复。
- **思考档位色彩平滑过渡**：思考档位胶囊在切换中、低、高、最大各档位时增加柔和的颜色过渡动画，动效更自然。
- **上下文轨迹文本自由复制**：思考过程与上下文轨迹窗口支持自由划选文本并复制，并保留顶部一键全量复制按钮。
- **修复思考模式下的 400 报错**：修复 DeepSeek 思考模型在历史消息中缺失 `reasoning_content` 导致服务端校验拦截的异常。
- **修复交付产物跨节点混淆**：规范 delivery 文件引用范围，通过 `goalId` 与 `nodeId` 严格隔离指针。
