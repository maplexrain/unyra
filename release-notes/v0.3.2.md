归一 Guiyi v0.3.2 —— 超级导师的任务被整理成一套「工作流」：开讲前先摸底、想玩实验一句话启动，还能让它把你常用的流程登记成模板随叫随到。超级文档学会直接写 markdown 与公式，页签与本地文件多了一层「不会悄悄丢东西」的保护。

## 新增

- **工作流系统**：开讲、回忆、出卷这些「导师代跑的任务」统一成了可管理的模板，分三级——内置（随应用提供）/ 全局（所有学习目标可用）/ 目标级（只在当前目标可用）。
  超级导师设置新增「工作流」分页：三级列表一目了然，能看的能跑、能删的能删。
  想加新的？在对话里让导师登记（「把这套流程做成工作流」），它存的是完整任务指令，
  触发时以一条用户消息进入上下文，不占系统提示词。
- **开讲流程升级**：新建知识点时，导师会先整理出前置知识、用一张表单问你「哪些已掌握 / 会一点 / 完全不会」
  （会先响铃、并把对话栏切到主位），再按你的盲点定详略，生成针对性的教学文档——不再自顾自从头讲到尾。
- **超级实验室**：输入框「更多 → 超级实验室」——用一句话告诉导师想做什么实验 / 需要什么功能，
  它会生成一份可交互的超级文档并当场打开。
- **超级文档内置 markdown 组件**：`<moji-markdown>` 元素里直接写 markdown，说明文字、列表、表格自动排版，
  **数学公式**用 $…$ / $$…$$ 的 LaTeX 写，宿主用 KaTeX 渲染——不用再手写 HTML 拼公式。
- **超级文档跳转语法**：文档里写 `[文字](moji:super/文档名)`，点一下就翻到本知识点的另一份超级文档
  （跨知识点也可以）；教学文档与笔记里的同名语法同样可点。指名不存在的文档会有提示，不会开出空页签。
- **关页签保护**：关闭有未保存改动的页签（含「关闭其他 / 全部关闭」这类批量操作）会先问一句：
  保存并关闭 / 放弃改动并关闭 / 取消。「关闭」从此真的意味着「不要这版改动」。
- **本地文件外部变化监听**：拖进来的文件在外部被修改时——你没在应用里改过，页签自动同步成磁盘上的新版；
  你正在改，保存时会先问：覆盖外部那一版，还是把手上的另存成新文件。

## 变更

- 导师交付的东西落在文档区时（写完教学文档、大纲、超级文档），会把文档区切回主位请你过目；
  要提问时才把对话栏切过来——看哪边由「接下来该看什么」决定。
- **上下文占用圆环逐跳实时**：一轮编排里模型来回好几跳，圆环现在每跳结束就更新，
  不再等整轮跑完才动；浮层里也写明了缓存命中率的统计口径（每次请求按输入量加权）。
- 侧栏的分区标题（知识节点 / 本地文件）与右上角按钮加大了一号，更好认更好点。
- 文档区悬浮组不再有「回忆」按钮——入口收敛到输入框「更多」菜单与学习状态面板。

## 修复

- 超级文档的滚动条永远是一根系统默认灰条、不跟主题——已修，现在与应用同款并实时换色。
- 超级文档里写公式会散架（渲染容器里缺 KaTeX 样式）——已修。
- 超级导师设置的工作流列表长了滚不动——已修。

## 说明

- 升级不会碰任何学习数据，也不需要重新激活。工作流登记（全局与目标级）会随数据目录一起保存。
- 安装包没有代码签名，Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。
