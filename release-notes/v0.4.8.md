归一 Unyra v0.4.8 —— 每个节点都有一个真实的工作区目录（就在节点目录里，能新建、能改名、导师也能读写）；间隔复习上线：节点学会后自动排 +1/+3/+7/+14/+30 的复习计划；试卷首次及格自动打卡；导师的多跳回复与缓存命中做了一轮底层修正。

## 工作区：节点目录里的真实文件夹

- **每个节点都有一片工作区**：`users/{uid}/docs/{目标}/{节点}/workspace/`（目标根节点就是 `docs/{目标}/workspace/`），是磁盘上真实存在的目录——在系统资源管理器里看得见、可以直接往里放任何文件。
- 资源管理器里每个节点下常驻一行「工作区」，展开就是磁盘上实际有的文件与子目录；右键**新建目录 / 新建文件 / 重命名**——建完当场起名，改的就是磁盘上的名字，绝不覆盖已有目标；文件与目录都能一键在系统资源管理器里定位。
- 导师也能读写工作区：`workspace.list / read / write` 三个新 api，路径写法与文档一样（`极限/数据/实验.csv`）——要交付「拿得走的文件」（整理好的资料、数据、代码）就放这里，别只留在对话里。
- 工作区跟着知识树走：改标题随目录一起搬家（与资源库同一套保护，同步与异步两条落盘路径都覆盖），启动时不会被当成教学文档解析，子节点目录也不会与它撞名；删除节点时它跟着一起删——确认框里那句「含它的全部文件」说的就是它。

## 资源管理器

- **目录图标统一颜色**：目录永远是「文件夹形状 + 同一个中性灰」，一眼认出这是目录、不与文档混淆；文档行仍按类型着色。
- **四个目录默认显示**：笔记 / 试卷 / 超级文档 / 工作区常驻，空目录也给出右键新建的入口——第一次初始化不必先想「目录在哪儿」。

## 间隔复习

- **计划是系统建的**：节点首次变「已掌握」时自动铺好 +1 / +3 / +7 / +14 / +30 五个阶段；到期没做保持「待复习」、不自动顺延；补做时更早的阶段自动并入这一次。
- **顶栏新增「复习」入口**（有到期时亮红点）：按目标分页——到期的复习、接下来两周的日程、已掌握但还没有计划的节点（可一键补建）。
- 复习以对话进行：**先主动提取再检查**，五个阶段各有侧重；**完成不看对错**——交互做完就算完成，错法进错误记忆、这次答对了的旧薄弱项标「已修复」（再犯自动清掉标记）。
- 强相关节点的复习可以**合并**：导师会先问你（列出节点与相关理由），同意后合成一组、后续阶段整组复习、落账各管各的，随时可以拆散。
- 大纲页的节点行显示复习进度：到期了亮出来（含逾期天数），没到期就说下次是哪天哪一档。

## 打卡：考试通道

- 目标下的试卷**首次考试**达到及格线（卷面 60%）即自动打卡——用考试验证过的学习不只导师出题一条路。它与出题通道分开记账，考试的分数不占出题的重试次数、也不会被其量级夹坏。

## 导师的底层修正

- **多跳回复的历史逐跳还原**：一轮回复可以来回好几跳（思考 → 工具 → 再思考），此前重启后整轮折叠还原，从第二跳起就与实发对不上、服务端缓存整段作废——现在按跳边界逐跳重放，与实发逐字节一致；并新增前缀门禁，注定不命中的请求直接拦下。
- **请求级命中率日志**：每次请求在控制台打出缓存命中率（服务端没回报用量时明说「未知」，不假装是 0%）。
- **中断恢复**：轮次进行中增量落库；进程被强杀后重新打开，那条没收口的回复会被接住，不再留下「跑一半消失」的对话。

## 修复

- 大纲页的导语 / 节点描述 / 条目摘要此前按纯文本显示，现在正常渲染 markdown。
