归一 Unyra v0.8.1 —— 互动课堂课件契约可见化与结构校验、存量课件打开自愈、组件属性文档对齐、关窗连击安全阀按窗口隔离。

## 互动课堂：课件契约与生成链路修复

- **课件结构契约一次给齐**：新增 `api.classroom.schema()`——LessonScene / 动作类型 / 动词白名单 / 1920×1080 画布布局常量与预置舞台类 / 最小完整课件示例，写课件前先对齐契约，不再猜字段（动作列表字段名是 `actions`，不是 beats）。
- **两套动效表显式分开**：`verbs()`（时间轴逐条调度的 action.verb 白名单）与 `animations()`（换幕挂载播一次的 data-anim 入场表）分成两张表命名，杜绝把动效名想当然填进动词导致的画面静默失效。
- **写入结构校验**：`editContent` 现在拒绝未知动词、悬空目标、缺画面、类型不认识与藏 `<script>`/`on*` 事件的课件，并回一句能据此改对的人话；句号、超长句、字幕冗余、隐藏元素死锁随保存回执给出提醒。
- **静态体检**：新增 `api.classroom.check()`，对已存课件查动词白名单、目标与元素 id 对号、字幕纪律与隐藏元素死锁，交付前自查。
- **组件属性文档与实现对齐**：`ui-concept` 的 `summary`、`ui-formula` 的 `note`、`ui-badge` 的 `variant` 等示例属性展开器根本不读，已全部按实现修正；`ui-steps` / `ui-quiz` 的子节点约定改为 `<ui-step>` / `<ui-option>` 标签；补上漏登记的 `ui-split-3`、`ui-grid-2x2`、`ui-step`、`ui-option` 四个组件。
- **动效命名按实现对齐**：卡牌库宣传的 `slideInUp` / `slideInDown` 与实现名不一致导致一半滑入动效落空，已更名为 `slideInBottom` / `slideInTop`；时间轴动词同步支持 slideIn 系列。
- **checkpoint 语义写明**：只暂停画面让学生自己思考，不判分——随堂选项展示用 `ui-quiz`，同样没有判定回路。

## 存量课件打开即崩修复

- 旧版生成的课件把动作写在自造的 `beats` 字段上，打开课堂页签会整页白屏：读盘时自动采纳为 `actions`（缺字段补默认、垃圾条目丢弃），时间轴聚合与调度器循环全面兜底——坏课件重新打开即可正常播放，无需迁移。

## 课堂节点挂载与交付

- 教学文档可以连线挂载 / 摘除互动课堂节点（与创建时挂载同一条树边）。
- `node.list()` 新增 classrooms 段（uuid / 标题 / 上游文档），「分析上游教学文档」不再靠猜。
- 交付登记 `delivery.submit` 支持课堂节点（uuid 直接可填）；点击交付记录直接打开对应课堂页签。

## 工作流提示词与指令分离

- 「生成互动课堂」工作流指令收缩为两行 + 契约指针，操作规程与教学要求移入系统提示词「内置工作流与任务规程」专节，回归其他内置工作流的「指令只写做什么与参数」纪律。

## 稳定性

- 关窗连击安全阀按窗口隔离：关 A 窗后 1.5 秒内去关 B 窗不再被误判为「双击强制退出」（辅助窗口并存是常态）；兜底对话框计时器统一管理。
- 沙箱 API 探针补齐互动课堂组七条用例，名单对账从此覆盖全部课堂 API。
