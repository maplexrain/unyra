归一 Unyra v0.5.5 —— 资源管理器收敛成一套零件、当前页签自动定位；导师获得「看网页请求、直接发请求」的能力；修掉 chip 引用被拆碎与并发写丢数据两颗钉子。

## 资源管理器

- **当前页签自动定位**：切换页签、导师打开一份文档、点对话里的引用——侧栏会自动展开它所在的目录、滚过去闪一下。笔记、试卷的历次副本、工作区文件、收藏里的网页都认得路；导师重开你正看着的文档也会重新定位。
- **分类夹收敛成一套零件**：学习目标 / 收藏 / 本地文件 / 最近打开与树里的目录行现在是同一套组件——同一深度永远同一缩进（原先千奇百怪的左缘对齐了），目录里的文件计数不用点开就有，右上角的新建 / 打开按钮统一为悬停显示，展开收起是同一拍动画。
- 收藏的分组行补上了展开箭头与高度动画（原先全侧栏掉队的那一个）。

## 网页页签

- **右键菜单加「检查元素」**：打开独立的 DevTools 窗口并定位到你点选的元素——看网页脚本报错、调样式不再需要别的工具。

## 导师（agent）

- **看网页的请求，然后直接发**：导师可以查看页面自己发出的网络请求与控制台输出（清单折叠去噪、逐条看详情），摸清请求形态后带着登录态直接重发——复杂的网页操作从「一次次模拟点击」变成「一发命中」，又快又稳。
- **等待与键盘**：新增 waitFor（等元素出现 / 等网络空闲等五种条件）与按键注入；页签截图带回执编号；还有区间日志录制——导师请你完成它做不到的操作（登录、验证码）时，它只分析你操作那一段的日志。
- 导师的执行指南按两轮真实使用反馈打磨：失败的处理口径统一、长网页响应落到临时文件不占对话、emoji 密度设了硬上限。

## 修复

- **对话里的引用 chip 被拆碎**：`#[{…}]` 引用在渲染时被 markdown 的自动链接吃掉结尾，显示成一段裸文本加一条红链——现在渲染前后用哨兵符保护，引用恢复成完整可点击的一颗。
- **并发写丢数据**：同一份数据文件被紧挨着写两次时，两次写会互踩同一个临时文件（控制台刷「写入失败 … ENOENT」），后写的内容被丢——现在同一目标的写盘排队串行，state.json 的保存不再撞车。
- KaTeX 不再对公式里的 emoji / 中文刷控制台警告（这些字符本来就渲染不出，告警只是噪音）。
