# 归一 Unyra v0.4.10

这一轮全部是文档区与页签的打磨：

## 标题大纲

- 大纲入口收进文档区右上角的悬浮组：悬停一颗按钮，标题大纲以气泡形式从按钮方向展开（入场沿对角线长大、退场原路收回），点条目缓动跳到对应标题
- 左侧常驻的标题栏与其「固定」功能已移除
- 外部 Markdown 文件（拖进来浏览的那种）同样支持标题大纲

## 链接

- 正文里的锚点链接（`[文字](#标题)`）可以跳转了：按 GitHub 的 slug 规则匹配标题，缓动滚动并播放落笔高亮
- 指向另一份 Markdown 的相对链接（如 `[docs/README.md](docs/README.md)`）点击即打开对应标签页：外部文件相对所在目录解析，内部文档按文件名匹配同名笔记
- 图片外链（`[![图](x)](y)`）保持行内排版，与 GitHub 一致；图片圆角缩小

## 外部 Markdown 预览

- 预览改用 GitHub 严格语义：软换行不再折行——README 里一行一个的徽章现在并排流开，而不是竖着摞成一列

## 页签

- 修复页签过多时不出现横向滚动、页签画进相邻栏的问题（根因是收起动画的 grid 未锁定列轨）
- 右键拖棱形换页签：棱形与指针保持相对距离，压到哪枚页签就吸附到其正中间并激活
