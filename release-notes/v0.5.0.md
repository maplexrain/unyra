归一 Unyra v0.5.0 —— 超级导师可以派「子代理」了：内置的网络检索代理开箱即用，让它查资料、核事实、交一份带出处的报告；你也可以让导师自己定义专属子代理。读网页与搜索这一路也整体提速、少踩坑。

## 子代理

- **派活**：对话里让导师「去查一下…」「核实一下这个说法」，它会把独立的活派给子代理。子代理有自己的上下文、自己跑完整流程，**只把一份交付消息交回导师**——中间的搜索与工具过程不占导师的上下文。一轮派多个时导师会等全部做完再继续。
- **看它干活**：输入框右下角新增机器人图标（有子代理会话才出现，带数量）；点开在输入框上方列出会话，点进去能**实时看到它的输出**，和看导师干活一样；左上角「返回」回到导师对话。子会话只读——它只接受导师的调度。
- **内置「网络检索」**：多引擎搜索（百度 / 必应 / 谷歌 / Yandex / 维基百科，可并行搜多家）、读原文核实、过滤广告与低价值结果，交付一份**每个关键事实带来源 URL** 的报告；查不到会明说，不编造。
- **自定义子代理**：让导师定义（角色提示词 + 允许使用的能力），登记后随时复用；同一个子代理的会话在一段对话里持续累积——它记得上次读过什么。
- **会话跟对话走**：随对话一起保存，重启应用后照样能翻开；删除对话时一起消失。中途点「停止」会连子代理一起停，回执里会说明「已中断、无交付」。

## 读网页与搜索更稳

- 抓取带完整浏览器指纹，**403 / 429 自动换一套指纹重试一次**——「搜索到了、打开 403」的挫败感大幅减少；
- 必应的跳转链接在解析时就还原成真实网址，读原文不必再过会拦抓取的跳转器；
- 结果摘要先行：先用摘要筛选，确需细节才抓原文；某页 403 就换来源，不恋战。
- 导师自己也能用 `web.search` 了：要实时信息、要核实事实时，一次调用并行搜多家引擎。
