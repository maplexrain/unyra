归一 Unyra v0.7.3 —— 公告配图内存与磁盘持久化二级缓存、文本高亮修复与荧光笔选中态、Quote 精读引用卡片与精准行跳转、Agent 全量提示词分层重构与稳定性升级。

## 公告配图内存与磁盘持久化二级缓存

- **弱网防裂图与极速秒开**：
  - 针对国内与弱网环境下 GitHub Pages / 外部图床访问不稳定、超时及裂图问题，引入内存与磁盘持久化二级缓存系统；
  - 磁盘缓存落在用户数据目录的 `notice-image-cache/`（与 `global.yaml` 全局配置同源，重启与离线依然可用），支持最近 60 条记录动态 LRU 清理，磁盘开销始终可控；
- **静默后台预加载**：应用启动或轮询取回公告列表后，自动对所有公告内容里的配图发起静默预取与持久化落盘；
- **渲染代换与优雅降级**：
  - 弹窗渲染时优先以本地 `data:` URL 代换，杜绝重复网络请求；未命中时在后台通过主进程自带重试机制的通道拉取并无缝响应式更新；
  - 内容区增加错误捕获与静默优雅降级处理，彻底消除难看的原生碎图图标。

## 文本高亮修复与荧光选中体验升级

- **Markdown 正文高亮修复**：修复 Markdown 引用块内部普通文本段落（`meta.paragraph` / `text.html.markdown`）被误识别为代码 meta 导致中文正文全盘变蓝的语法高亮 Bug，恢复清晰墨色。
- **荧光笔选中背景色**：将全局与引用块内部的文本选中态（`::selection`）升级为明亮、清爽通透的荧光黄高亮与提亮文字；`.moji-quote-mark` 同步升级为直角荧光马克笔质感与微发光效果。

## Quote 原文精读引用卡片与精准行跳转

- **视觉与语法重构**：
  - 去除 Quote 卡片外层容器多余边框与内边距，使引用卡片平滑自然嵌入讲义段落；
  - 语法升级为 `mark(start:col, end:col)` 样式标记体系，支持对特定行列文字进行荧光标记；
- **一键直达源文件引用行**：
  - 点击引用卡片头部文件名或「打开」按钮时，自动将引用行号区间换算为源文件字符偏移量，广播并优先以源码视图跳转至对应文件、高亮选中该引用行区间并平滑滚动至视口中央；
  - 支持已打开页签的实时选区响应与预览视图下的段落荧光闪烁提示。

## Agent 首轮全量提示词架构重构与稳定性优化

- **首轮全量注入与可变性分层排序**：
  - 废除按需注入机制，首轮直接注入全量系统提示词（含全部 execute API 与工作流规范）；
  - 严格按可变性从低到高分层排序：底层稳定能力与安全纪律在前，动态人格、文档格式及用户画像分层靠后，兼顾模型前缀缓存命中率与灵活切换；
- **解决目标无根节点阻塞**：修复目标未设根节点时导致 `workspace.write`、`ui.point` 报残缺对象的隐式阻塞，将无根节点显式化并完善提示词指引；
- **结构页签去重**：修复目标设根前后可能导致界面同时出现两个「结构」页签的问题；
- **项目与文章解读工作流规范**：规范化网络素材自动抓取为本地项目节点并运用 quote 块进行精读引用的完整引导闭环。
