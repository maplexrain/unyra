归一 Guiyi v0.3.0 —— 这一版有两件大事：外观迎来十一套新主题（应用标志、托盘、窗口底色都跟着换装），超级导师补上了一整批人机协作能力（表单提问、长期记忆、任务预告、界面操作），顺手把「上下文缓存命中率极低」这个老毛病修到了根上。

## 新增

- **十一套新主题**：樱花粉、静谧蓝、清新绿、纯白、纯黑、暖纸、琥珀、雾紫、石墨、夜航蓝、高对比。
  设置 → 外观里每套带色板圆点，挑起来直观；「跟随系统」保持只在浅色 / 深色之间切换，其余主题选定即固定。
  应用标志、托盘、窗口底色、Alt-Tab 图标都会跟着主题换装；顶栏那颗主题按钮保留「跟随系统 → 浅 → 深」的快速轮换。
- **超级导师会把问题做成表单**（结构化表单提问）：单选 / 多选自动附「其他」补充输入，简答直接打字；
  可以一次问好几道，还能「前面选了什么，后面问什么」。表单压在输入框上方，响铃提醒，回答之前导师一直等着。
- **任务预告**：导师接下来要做什么，会以清单形式显示在输入框上方（只是预告，不是待办，不能勾选）。
- **长期记忆**：导师会把对你的判断与偏好（讲解习惯、已定下的约定）记进长期记忆，跨对话有效；
  记忆不会自动塞进上下文——需要时它自己取用。想清空随时可以。
- **导师可以操作界面了**：把对话栏 / 文档栏换到主位、弹吐司提示、在页签里打开某个知识点并定位到某一行或选中一段文字、
  滚动文档区、把文档区截图附进对话、查看与点击文档里的元素。
- **开发者工具**（超级导师设置 → 开发者，口令解锁）：
  **上下文比对调试器**——每次发给模型的上下文留一份快照，两两比对直接定位「差异出现在第几条消息、第几个字符」，排查缓存与提示词漂移用；
  **execute 沙箱 api 目录**——当前导师可用的全部 api 与用法一览。

## 修复

- **上下文缓存命中率极低的大头修掉了**：对话历史在「一句话 + 一次工具调用」的回复上与实发结构不一致，
  导致服务端前缀缓存整段作废、之后每轮全价重算。修复后命中率恢复正常，长对话的响应速度与费用都会明显改善。
- **Command Code Go 套餐现在回传真实 token 用量**：圆环占用与缓存命中率不再是本地估算，命中率视模型可达 90% 以上。
- 文档区截图此前只登记进资源清单、文件没落盘，已修。
- 按行号定位文档对带格式的内容（标题、列表、链接）失效，已修。
- 沙箱超时从「总时长」改为「无活动空闲时长」：等用户回答表单、合法的长编排不再被误杀。
- 页签的关闭按钮改为鼠标经过时才显示，选中的页签不再常驻一个 ×。

## 说明

- 任务栏按钮的图标在 Windows 上由快捷方式 / exe 决定（平台规则），保持印章红不变；托盘与应用内标志跟主题走。
- 长期记忆存在你的数据目录里（目标目录下的 mind.json），升级无感；升级不会碰任何学习数据，也不需要重新激活。
- 安装包没有代码签名，Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。
