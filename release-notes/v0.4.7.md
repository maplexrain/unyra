归一 Unyra v0.4.7 —— 目标与大纲：每个目标一份交互式大纲页，节点统称目标（总目标 / 阶段目标）；资源管理器把文档收进目录、删除可以 Ctrl+Z 撤回；导师学会迁移节点与写大纲。

## 目标与大纲

- **节点统称「目标」**：一个学习目标的根是**总目标**，它下面每一层都是**阶段目标**。
- **每个目标都有一份大纲**：创建目标的那一刻，教学文档与大纲两份文件同时成形
  （`{节点}.md` + `{节点}.outline.json`）。大纲在页签里打开是一个**交互页面**——
  导语 + 直接子目标清单，每一条都带着它的学习情况（自评、掌握度、最近的检验、
  错误记忆、上次学习、考过几场）。
- **大纲只写直接子层级**：一层为止——「爷爷知道儿子的存在，但不知道孙子的存在」。
  展开一个子条目，读到的就是那个子目标自己的大纲，逐层下去直到叶子。
  这条规矩对导师是硬性的（数据形状保证，写不进第二层）。
- 大纲里还没创建的子目标可以**「创建并开讲」**：当场建出子目标、交给导师开讲，
  建出来的节点与大纲条目自动对上号。
- 导师侧的新能力：`outline.read / outline.write`（整份读写大纲）、`node.move`
  （把节点迁移到另一个节点之下——目标的根、跨目标、会成环的移动都会被拒）；
  `node.create` 收紧为**必须写明 parent**，不再隐式建在「当前节点」之下。
- 工作流更新：「学习大纲」的交付物是大纲页（教学文档只写总述，不再把大纲整篇塞进去）；
  「开讲」会把这一层的子层级顺手写进大纲；新增内置工作流**「生成大纲」**——
  大纲页上随时可以请导师规划 / 重排这一层。

## 资源管理器

- **大纲像普通文档一样显示**：展开节点后置顶两行——学习文档与大纲。右键大纲行：
  打开大纲、让导师重排、在文件管理器里定位那份 `.outline.json`。
- **笔记 / 试卷 / 超级文档收进目录**：各自一层、可开合，摆在**下级节点之上**；
  行尾带数量徽标，**默认收起**——先看有什么、有几份，点开再铺内容；
  空目录不显示；右键目录直接新建对应的东西。目录用**文件夹图标**（开合跟着变），
  与一份份的文档行（类型图标）一眼区分，颜色仍按类型身份走。
- **展开收起有动画**：目录、历次考试、下级节点的高度过渡 + 单箭头旋转；
  系统开了「减少动态效果」时自动关闭。

## 撤回（Ctrl+Z）

- 资源管理器里的删除都可以 **Ctrl+Z 撤回**：删除节点 / 目标（连带整棵子树、试卷、会话、
  阅读与打卡两本账）、删除笔记、删除超级文档、删除试卷、从列表移除本地文件。
  删除确认框与吐司里都会提示可以撤回。
- 撤回恢复的是**数据**：删掉的子树原样回来，阅读与打卡的账一分不少（删除之后其他节点
  新攒的阅读记录也不会被抹掉）；关掉的页签需要重新打开。
- 在源码编辑器里 Ctrl+Z 仍然是文字层面的撤销，两边的撤销互不打架。

## 对话区

- 输入框支持**斜杠命令**：输入 `/` 唤起菜单——出试卷、设置推理等级、压缩上下文、
  新建对话、对话历史、超级实验室、超级导师设置。
- 资源管理器新增**学习文档行**：点它打开教学文档（与切到这个节点是同一件事）；
  这一行上没有「删除文档」——删它就是删节点本身。

## 一批修正

- **会话标题能起出来了**：上限从 10 token 改为 30 字符，补全的输出预算给足
  （推理模型的思考与正文共用预算，之前只给 40，思考一烧就空——每次起名都
  「成功返回空串」）；起名请求不再携带 temperature（一部分 OpenAI 兼容网关见到它直接 400）。

## 内部

- **LearnWorkspace 工程化拆分**：4190 行的学习区宿主拆到 2065 行——两列机制、
  保存 / 关闭 / 冲突、导出、考试工具注入、页签拖拽、链接处理、库操作、概念动作、
  番茄钟、工作流启动器各归 `workspace/` 下一个模块，宿主只留状态编排与装配；
  新机制从此不再往宿主文件里长。
- 新增沙箱 api 走完整条对账链（注册名单 / api 目录 / execute 参数 / 指令文本 / README），
  agent-ops 探针 **713** 项、单元测试 **578** 项全部通过；撤回与各删除函数的级联
  逐项互逆有测试钉着。
