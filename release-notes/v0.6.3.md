归一 Unyra v0.6.3 —— 写作策略改造（导师人格 / 文档格式）、更新策略（正式版 / 尝鲜版）与远程公告系统：导师的表达风格与文档排版格式随时可切、下一轮生效；更新接收通道分两档、切换即时生效；公告改从远程拉取，顶栏红点提醒，支持多条与配图；另有页签与文档组生命周期的一批边角修复。

## 写作策略：导师人格与文档格式

- **入口换新**：输入框底行的「人格」按钮升级为「写作策略」（滑杆图标），两级菜单分别管理「导师人格」与「文档格式」，切换后从下一轮对话开始生效。
- **导师人格**：简洁导师 / 标准导师（默认）/ ADHD 导师——控制导师讲解的详略与节奏。
- **文档格式**：混合（Markdown 为主，默认）——Markdown 能表达的一律用 Markdown、HTML 只做交互与复杂结构；纯 Markdown——只用标准 Markdown 语法，最大程度兼容 Obsidian / Typora / GitHub 等编辑器；纯 HTML——此前版本的默认排版策略（数学公式仍用 $$…$$）。
- **两种策略都随对话注入**：不走设置弹窗，改完下一轮生效、历史消息不受影响；长对话被压缩后自动重新注入，不会丢。
- **格式联动**：纯 Markdown 下不再注入 HTML 排版模块，排版检查随格式自适应；系统提示词补充 LaTeX 兼容性注意事项（定界符、核心子集命令、中文放 \text{}）。

## 更新策略：正式版 / 尝鲜版

- **两档通道**：设置 → 更新里可选——正式版只收 X.Y.Z 正式发布；尝鲜版连 X.Y.Z-beta.N 尝鲜版一起收（发布端按版本号后缀分档，尝鲜版不占 Latest）。
- **切换即时生效**：换档后立刻按新策略重新认定一次（自动检查关着时只清状态、不联网）；正在下载的包让它下完，下完按新策略重查；不降级——从尝鲜版切回正式版会停在当前版本，等正式版版本号真的更高再升。
- **标识与防线**：设置页、更新状态行与更新入口新增「正式版 / 尝鲜版」标识；正式版客户端即使遇到发布端误标也不会被推进尝鲜版。

## 远程公告系统

- **公告改从远程拉取**：启动时取一次、之后每 5 分钟轮询；顶栏喇叭按钮带未读红点（ping 动画），轮询期间新到的公告会点亮。
- **多条公告**：弹窗用页签摊开，打开时自动落在第一条未读；竖屏弹窗 546×818。
- **支持配图**：图片托管在公告仓库（Pages 托管），应用内直接查看。
- **本地编辑器**：`npm run notice` 打开公告编辑器（零依赖、只监听本机 127.0.0.1），改完推送到公告仓库即可全端生效（见 docs/notice.md）；数据格式 `{ enabled, notices: [...] }`，兼容旧式单条公告。

## 工作区与页签细节

- **非文档类产物统一进工作区**：系统提示词立了一条规矩——交付物（文件 / 项目 / 代码 / 报告等）凡与教学文档 / 笔记 / 超级文档 / 试卷无关的，一律写当前节点的工作区目录，不再散落别处。
- **页签与文档组生命周期修复**：笔记等节点文档先经过根大纲组、不再成为孤儿页签（旧状态里的孤儿会被自动修复）；强制关闭关联文档时保留空白落点，不再「关掉 Agent 却自动翻出另一份文档」；删除目标或强制关闭时连暂存页签一起清，避免日后被恢复成没有来源的文档。
- **页签滚动居中改平滑过渡**：激活页签滚到栏中间从瞬移改为平滑滚动，系统开启「减弱动态效果」时自动降级。
- **空白页快捷入口一行四张**：新建文件 / 打开本地文件 / 浏览网页 / 新建学习目标 由 2×2 改为一行四张，容器相应加宽。
