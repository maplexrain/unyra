归一 Guiyi v0.2.0 —— 这一版把「文档区」重新做了一遍：从「一个节点两份文档」变成 vscode 那样的资源管理器 + 自由页签。

## 新增

- **左侧变成资源管理器**：分成「知识节点」与「本地文件」两个可折叠区，都默认展开；本地文件为空时那一区不显示。
- **可以把外面的文件拖进来看**：txt / markdown / html 拖到窗口任意位置就会被收下并打开，内容不复制、仍住在原处，
  改完就地写回（自动保存，Ctrl+S 立即存）。拖进来过的文件记在「本地文件」里，按最近打开排序，下次一点就开。
- **文档区改成自由页签（像 vscode）**：节点的教学文档、任意一份笔记、任意一个本地文件平级地排在同一条页签栏上，
  页签上显示的是节点名（不再是「教学文档」四个字）。右键有关闭 / 关闭左侧 / 关闭右侧 / 关闭其他 / 全部关闭。
  **关掉某个节点的页签，它就不再是选中样式**；关掉的页签在重开应用后不会自己回来。
- **源码 / 预览两个视图**：页签栏右侧的开关。源码视图里文档可以直接编辑（含本地文件）；
  预览支持 markdown 与 html，可预览的文件默认就是预览，其余（txt 之类）默认落在源码。
- **一个节点可以有多份笔记**：每份笔记是一个独立文件（`{节点}.notes/{名字}.md`），可以新建、改名、删除。
  右侧悬浮组的「笔记」按钮向左展开一块面板，列出当前节点的全部笔记（名字与字数）。
- **右侧悬浮组**：回忆 / 学习状态 / 试卷 从文档栏搬到了文档区右边缘，与笔记按钮排在一起，不再和页签抢地方。
- **顶栏多了三颗按钮**（账号右边）：主题（点一下在跟随系统 / 浅色 / 深色之间轮换）、文档、联系方式。
  后两个先占位，之后分别接教学文档与反馈入口。
- **输入框左下角的「+」**：点开在输入框上方弹出与它等宽的菜单，目前是「新建对话」（顶栏那颗新建对话按钮因此删掉了）。

## 改进

- 应用里所有「AI 导师」统一改称**超级导师**；设置里的「AI」页签改叫**模型**。
- 思考等级的滑条：修掉了左侧条纹的接缝，条纹更白，滑块改成毛玻璃。
- 输入区上方那一条空白去掉了，消息列表与输入框之间更紧凑。

## 说明

- 老数据会自动迁移：`{节点}.笔记.md` 会变成 `{节点}.notes/笔记.md`（内容原样搬过去），读过一次并保存之后旧文件删除。
- 升级不会碰你的学习数据（都在 `%APPDATA%\moji-notes`，不在安装目录里），也不需要重新激活。
- 安装包没有代码签名，Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。
