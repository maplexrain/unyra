归一 Unyra v0.6.6 —— 随笔提交与按历史的增量整理、语音输入实时直填与可调降噪、目标形态交由导师自判，以及文档交互与工作区的一批打磨。

## 随笔：从随手记到可提交的知识源

- **提交与快照**：随笔窗口新增「提交…」。提交会把上次之后新写 / 改过的随笔封成一份**自足快照**——之后随笔再改、再删，回看这次提交仍是当时的原样。只提交有变化的内容，空提交不会产生记录。
- **Agent 按历史增量整理**：提交后自动跑内置工作流「随笔整理」。它拿到的是**提交历史**（之前几次分别改了哪些节点的哪几份笔记）、本次新增随笔的全文，以及本次修改随笔的**改动处**（公共前后缀差异，不重复贴整段）。据此只处理新增 / 修改，合并进上次对应的笔记，不把旧内容重做一遍。
- **整理结果可信可查**：动过哪几份笔记由宿主在整理前后各拍一次笔记指纹对比得出，不依赖模型自报；详情里逐条列出「节点 → 笔记（新建 / 更新）」，点一下直接打开那份笔记。
- **失败可重试**：没配 AI、模型报错、应用在整理途中被关掉，都会留下明确的失败原因；快照还在，点「重试整理」即可重跑，不需要重新提交。
- **提交后继续写、继续提交**：随笔不会被冻结。继续写就自动进入下一批待提交，下一次提交只带这次的新增与改动；窗口底部也给了「继续写随笔」。
- **窗口改版**：去掉左侧列表，顶栏改为下拉选择（空白 / 按日期，同一天多条带序号），右侧是提交、提交历史与删除；点开按钮仍是「圆变方」的几何变形，提交后窗口里直接展示整理进度与结果。

## 语音输入：边说边写，噪声自己调

- **实时直填**：去掉识别预览浮窗。说话途中每约 1.2 秒把这一段音频**整段**重解一次，用最新全文就地替换输入框里这一段已经写下的文字——文字越写越完整，而不是等停顿才出现。
- **静音不送识别**：人声判据只看**最近两秒的起伏与持续性**（最大值 ≥ 最小值的若干倍、且至少两块持续像人声）。风扇、空调、电流声是平的，再响也不算；连续 3 秒没人声直接丢缓存，不再对着空气「编字」。
- **标点噪声过滤**：识别结果若只有标点（模型对静音常吐一个「。」），一律当没听见，不会在输入框里留下句号；送识别前还会裁掉段首段尾的静音。
- **降噪强度可调**：设置 → 插件 → 语音输入新增滑杆（0–100，默认 30，立即生效）。越高越不容易把环境噪声当成说话，也越容易漏掉轻声；识别不到往左调，噪声多往右调。结束录音的兜底识别不随滑杆抬高，最后一句不会被吞。
- **落点修复**：多个导师页签常驻时，语音文字只会落进眼前那一份输入框，不再串到后台页签。

## 目标、工作流与文档

- **目标形态自判**：新建目标不再让用户选「长期学习 / 一次性任务」，改由导师从首条消息与附件判断——有具体制品（项目目录 / 论文 / 报错日志）按任务型，有长期意图（系统学 / 掌握 / 从零学 / 备考）按学习型；只有两种信号同时成立时才问一次。
- **精简功能**：移除打卡、复习、回忆与探针；「压缩上下文」推荐档改为 none（摘录式改写，不需要额外推理）。
- **划词右键菜单**：预览里选中文字后右键，可复制源文、粘贴替换选中段、或切到源码视图定位这一段。
- **Mermaid 与图片**：放宽节点标签折行（10 节点竖链从 1201px 收到 1006px），超过一屏的图默认折起、可展开；正文图片恢复行内排列，徽章不再竖着摞成一列。
- **工具调用失败分色**：区分「调用级失败」（代码跑完了，但某次 api 没生效，黄色）与「代码级失败」（编译 / 运行 / 超时，红色），不再一律标红。

## 交互与性能细节

- **资源管理器**：「新建学习目标」按钮常显并加大，不再悬停才出现。
- **空白页签**：快捷入口顺序改为 新建目标 / 新建文件 / 本地文件 / 浏览网页。
- **新建文件页**：右上角文档悬浮组不再压住页头的「保存…」按钮。
- **输入框状态行**：去掉「正在辅导『xxx』」，只保留对话标题与轮次 / 速度 / token。
- **切签与画布**：正文子树与「生成文档」回调保持引用稳定，切页签不再整棵重渲；撤掉空大纲浮层与节点卡片的贴边，空文档页给出生成入口。
- **工作区**：修复网页 chip 拖入产生重复页签；非输入触发的对话请求改用眼前正在显示的会话；导图预览不再自动收起。
