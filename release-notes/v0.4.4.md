归一 Unyra v0.4.4 —— 代码块有了真正的高亮（VS Code 那套 TextMate 语法），文档的语法与渲染也改成了插件：内置的可以关，自己的可以装。

## 代码块高亮

- ```js / ```python 这类围栏现在按**VS Code 同一套语法**着色：40 门语言（js、ts、jsx/tsx、py、rust、go、java、c/c++、c#、php、ruby、kotlin、swift、shell、powershell、sql、json、yaml、toml、xml、html、css、scss、less、markdown、diff、dockerfile、ini、lua、r、dart、vue、latex、haskell、scala、elixir、zig、graphql）。
- **按需加载**：文档里第一次出现某种语言才去取那份语法，之后再遇到直接用缓存；没有代码块的文档一分钱不花（连高亮引擎都不加载）。
- **颜色跟着应用主题走**：浅色一套、深色族一套，切主题是纯 CSS 的事，不重新解析代码。注释斜体，字符串、数字、关键字、函数名、类型各一色。
- 没写语言的围栏（``` 后面空着）保持纯文本——不猜语言：把一段 Python 按 JavaScript 染色，比不着色更糟。
- 导出 HTML / PDF 里同样是彩色的。
- 单块特别大（3000 行 / 15 万字符以上）时不着色，直接显示纯文本：不拿主线程去赌一段日志。

## 文档渲染插件

- **设置 → 插件**：插件按**类别**列出来（目前是「Markdown 文档插件」），**内置的也能关**：
  - **函数图像**（```plot）：默认开。关掉之后 ```plot 就退回普通代码块。
  - **代码块高亮**：默认开。
- **自己装插件**：把一个 .js 放进数据目录的 `plugins/`（设置页里有「打开插件目录」），在里面 `register({...})` 就能：
  - 认领一种**围栏语言**（写 `render` 产出 HTML，需要画图的再补 `hydrate`）；
  - 或者只写**正文文字规则**：给全篇的引号描边、给某些符号换色这类小加工，不必去碰 Markdown 语法本身；
  - 或者接 marked 的扩展（`==高亮==` 这种行内语法）。
- 插件默认**不加载**，要在设置里点一次才启用。界面里也写明了：插件与归一同权（读得到正文与你的全部笔记），只装自己看得懂、来源可信的。
- 装完、开关完都要**重启**才生效（插件在启动时装载一次），设置页会提示这一点；装不上的插件会显示原因，不影响启动。
- 想抄现成的：仓库里 `docs/plugin-examples/quote-style.js`（引号描边 + 箭头换色），复制进插件目录即可。
