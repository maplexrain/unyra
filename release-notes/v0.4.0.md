归一 Guiyi v0.4.0 —— 试卷模块重做：卷子与「一次作答」分成两层，考试在独立窗口里进行，作答过程（输入顺序、每题耗时、切屏）全部留痕；交卷后导师判分并写错题讲解。这一版还补上了学习计划的地基：**有效阅读记录**、注意力评级、用出题验证的打卡与番茄钟。

## 新增

- **试卷模块重做**：试卷分成「卷子」与「一次作答」两层，一次考试的开始、作答、交卷、判分、讲解各成一条记录。
  - **独立考试窗口**：开考后另开一个窗口，主窗口盖一层遮罩——不会一边答题一边翻文档；窗口失焦、切走都会被记下来。
  - **作答过程留痕**：按输入顺序记录每一题的作答与改动时刻、每题思考时长（切屏与静置的时间不算）、是否超时。
  - **交卷即判分**：客观题当场出分，之后导师逐题判主观题、写错题讲解，并把错法记进学习状态。
  - **试卷副本页**：交过的卷子可以当普通页签打开，红绿对照看对错、错题讲解默认折叠。
- **有效阅读记录**：只记事实——读了多久、读到哪一节、什么时候被打断、展开过哪些折叠块。
  - 「有效」= 窗口在前台 + 页签在主位 + 真的在读；失焦、切走、静坐超过 60 秒、导师正在写这份文档的时间都不算。
  - **门槛**：今天第一次打开的文档，要先滚动 / 点一下（真的动过）并且读够 20 秒才开始记账——顺手划过去的页签不会留下记录。
  - 文档区底部一条 **4px 进度条**：一分钟一格、一格一种颜色，十格一轮回；停表时暗下去但停住。
  - 顶栏新增「有效阅读」入口：今天读了多久、读了哪些知识点、各读到第几节，以及最近七天。
- **注意力评级**：由阅读记录派生（中断频率、最长连续段、阅读节奏、交互密度、前后半场衰减），
  给出「专注 / 正常 / 断续 / 心不在焉」与一句建议，并据此调整教学节奏（讲长推导还是改短块、换题型）。
  它只影响「怎么教」，不进掌握度；样本不足时不给评级。
- **打卡**：不是点一下签到——题目只能出自**今天真正读到的内容**，答到门槛才算过，一天三次机会。
  答错不会「安慰式放行」，没过会告诉你差在哪、还剩几次。连续天数与日历在顶栏那颗「打卡」里。
- **番茄钟**：导师按你的阅读情况排一份专注清单（每条一件事、带时长），**开始与中止由你自己点**。
  顶栏那颗显示当前时间、正在做的事与剩余分钟；倒计时到点会提示，关掉应用再打开也能接着走。
- **学习者画像可以主动取**：导师不再默认知道你的背景，需要时会自己取一次；缺的字段会用表单问你，
  你提交的那一刻就直接进画像。

## 变更

- **卷面**：单栏 768px、题干与序号同行、选项无边框无底色；选项顺序是「序号 · 单选/多选控件 · 内容」，
  对错题不再显示序号与 true/false，直接写「对 / 错」。
- 答题时按作答顺序累计每题用时，交卷后能看到哪一题卡了多久。
- 删除试卷分两档：没考过的问一句，考过的会先列出后果（几次记录、讲解一起没）再确认。
- 用户信息不再默认塞进导师的上下文，改由它按需获取——既省上下文，也更贴合你当下的问题。

## 修复

- **有效阅读记录没有被保存**：写的时候写了、读回来时漏读了这几块字段，于是每次重启记录都被清空。
  同一个毛病还修了两处（拿旧快照覆盖旁路写入、导入备份时抹掉自己的记忆与记录）。
- **函数图像画不出来**：文档里写分数次幂（如 x 的三分之一次方）时，整条曲线会被当成「没有定义」而消失，
  控制台还会刷上千条警告。现在渲染时会自动改写成等价写法，曲线正常，负半轴也画得出来。
- 试卷里选项文字里的公式与公式链接不渲染成排版——已修。
- 鼠标经过试卷列表时的历史记录提示被滚动容器裁掉——已修。
- 超级导师设置里的工作流列表长了滚不动——已修。
- 顶栏时钟偶发把界面刷崩（React 报 Maximum update depth exceeded）——已修。

## 说明

- 升级不会碰任何学习数据，也不需要重新激活。阅读记录、打卡与番茄钟计划都跟着数据目录走。
- 安装包没有代码签名，Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。
