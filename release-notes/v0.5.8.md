归一 Unyra v0.5.8 —— 语音输入变成一件可开关、可配置的插件：识别引擎换成 sherpa-onnx，模型没下好时开关按不动，并直接告诉你去哪儿下。教学文档现在真的认 Tailwind 工具类——Agent 写在正文里的 class 当场算成 CSS，深色模式跟着应用走。顺带修掉应用身份（AppUserModelID）的一处老问题：源码运行不再冒充安装版身份，任务栏图标不会再被开发版带成 Electron 原子。

## 语音输入插件化

- **一件功能性插件**：语音输入从写死的输入框按钮改成「功能性插件」这一类——给应用加一项能力，与 Markdown 渲染插件分开。这一类默认关着：它们大多要先下模型、要占资源，没准备好就打开只会撞见一堆「还不能用」。
- **开关与模型绑在一起**：没下模型时开关按不动，拦话不是「不可用」，而是**下一步该做什么**（点进这一项去下，约 228 MB）。按钮挂在导师输入框上，配置独立成页（模型、语言、GPU 都在那儿配）。
- **识别引擎换成 sherpa-onnx**：原来的 whisper wasm 引擎退役。新引擎是原生运行时（.node + DLL），已按目录打进安装包并在 asar 外解出——操作系统加载 DLL 走文件系统，认不出 asar 里的虚拟路径。

## 教学文档认 Tailwind 了

- **写在正文里的工具类当场生效**：文档是 Agent 在你机器上现写的，类名不在任何源码文件里，构建期扫描看不到——此前文档里写 `bg-sunken`、`grid grid-cols-2` 是一点样式都没有。现在渲染进程里现算一份 CSS 注入页面，预览与导出共用同一个编译器。
- **只作用在文档正文里**：算出来的 CSS 会被限定在正文容器内，不会波及整个界面（`.flex` / `.grid` 满大街都是）。
- **写应用自己的令牌**：文档里可以写 `bg-paper` / `text-ink` / `border-line`，深色模式自动跟随，不用为两套主题各写一遍颜色。

## 修复

- **任务栏图标不会再变成 Electron 原子**：应用身份（AppUserModelID）单独成文件，源码运行另起一个（.dev 后缀），不再冒充安装版。此前把开发版固定到开始菜单，会让**安装版**的任务栏图标也变成 Electron 原子（2026-10 实际发生过）。
- 消息分组（思考 / 工具调用 / 正文）独立成模块，行为不变、可单独测。
- 提示词模块与沙箱 execute 接口收敛，中英文案补齐。
