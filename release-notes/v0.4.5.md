归一 Unyra v0.4.5 —— 代码块能编译运行了；打卡与有效阅读按学习目标分开算；对话更好读，也更少被打断。

## 代码块的伪编译与运行

- 鼠标经过代码块，右上角浮出三颗按钮：**复制 / 编译 / 运行**。
- **编译是伪编译**：把这段代码交给**超级导师**（内置工作流），由它转译成在这个应用里跑得起来的 JavaScript。
  - 文档里贴的往往是**半截代码**：导师会自己去读**这段代码所在的那篇文档**把缺的定义补齐；
    文档里也找不到的，就模拟一份合理的假上下文（假数据、假函数），并把假设写进说明——不会回一句「无法编译」。
  - **只有定义、没有任何会执行的语句**的代码（一段类型声明、几个函数）会被当场判成「无输出」，
    代码块上打一个标记并写明理由，此后不再编译、也不再运行——转译出来照样什么都不产出。
  - 产物**按内容寻址**：重启之后还在（按钮直接是「重新编译」的样子）；代码一改，指纹就对不上，按钮自己变回「编译」。
- **运行**在一次性 Worker 沙箱里跑（没有 window / document / npm），输出贴在**代码块下面**，
  结果里的 JSON 会排版上色，「本次调用 / 日志 / 哪几次没生效」渲染成注释。
- 代码里用到 `fetch` 时，**每次运行都要你点一次头**：联网的代码不会在你不知情的时候发请求。

## 打卡与有效阅读：按学习目标分开

学两门课时，两边的进度不该搅在一起。账本现在**一个目标一本**（落在各自的目标目录里）：

- **打卡**：每个目标一条连续天数、一道门槛（当天有效阅读满 15 分钟）、一天最多三次机会。
  顶栏那颗「打卡」鼠标经过向下展开：上面是日历（画**当前目标**那一本账），下面是**目标列表**——
  哪门课今天还差几分钟，读满的那一行自己变成打卡按钮。
- **有效阅读**：左边一列是过滤栏（「全部」+ 各个目标，各带今天的分钟数），右边是这一档的
  **按节点阅读统计**与最近一周的时长柱子。选「全部」就是所有目标合起来。
- 旧的那份用户级记录**直接丢弃**，不做迁移——重新开始算。

## 对话栏

- **工具气泡按工具说话**：`execute` 那一步展开后显示的是它写的那段 **JS 源码**（排好版、按 JavaScript 上色），
  不再是 `{"description":…,"body":…}` 那坨参数 JSON；结果同样排版 + 高亮，其中「关于这次调用本身的话」
  摘出来渲染成注释。
- **对话会自己起名**：新会话跑起来时，导师读**第一句话**起一个不超过 10 个 token 的标题，
  挂在对话栏右上角、也列在「更多 → 对话历史」里——列表里不再是清一色的「对话 1 / 2 / 3」。
- **「+」菜单分了两级**：「工作流」（回忆 / 超级实验室 / 打卡）与「对话历史」都是二级菜单，
  换层时新的一层滑进来、旧的一层滑出去（与输入框右下角那个「提供商 · 模型」选择器同一套手感）。

## 文档区右上角的悬浮组

- 从「右边缘竖着一列」改成**右上角横着一条**，而且**没有外壳**：没有边框、没有底色，
  几颗图标直接浮在正文上。
- 每颗按钮**鼠标经过向下展开**自己的那一块：笔记、超级文档、学习状态、试卷。
- **学习状态不再是一扇能拖的窗口**，改成一块两栏 tip：左边是「现在什么水平」（掌握度与依据、自评四档），
  右边是「一路上的痕迹」（错误记忆、检验记录），「回忆一下 / 探个针」在标题栏里。

## 少打断一点

工作流触发时不再一律把对话栏拽到眼前：**只有需要你回答问题的那种**（第一步是一张压在输入框上方的表单，
不回答就走不下去）才会响铃并切过去。「伪编译」这类交付物在对话里的**只响铃、不抢位置**——
你点的是代码块，回执也画在那儿。

- 升级不会碰任何学习数据，也不需要重新激活。
