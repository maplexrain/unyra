归一 Unyra v0.5.3 —— 界面打磨批次：对话面板更好用，右键菜单补齐，网页页签不再「吞」快捷键。

## 对话面板

- **Ctrl+Q 修正**：右侧栏装着导师时，Ctrl+Q 现在是真正的开/合切换；收起状态按它展开后，光标会自动落进导师的输入框（原来收着的栏接不到焦点，表现为「只能开不能收」）。
- **消息定位条合并锚点**：相邻的工作流分界条在消息列表里本就融成一条横线，右侧定位条现在一簇只落一个点，不再一串点指着同一条线。
- **消息区顶部渐隐**：内容滚出容器时在渐变里淡出，不再被上缘一刀切掉。
- **「回到最新」按钮**：圆形改为方圆角，图标换成下回旋镖，背景更收敛。
- 去掉输入框左下角的步数统计（轮数 / 速度 / token 保留）。

## 快捷键与手势

- **网页页签里应用快捷键恢复**：焦点在网页里时，Ctrl+S / Ctrl+F / Ctrl+H / Ctrl+E 与 F11（纯净阅读）现在都能用，不再被网页吃掉。
- **网页里的右键横划换页签**恢复：文档区那套手势在网页页签里也能用了。
- **文档区快速双击进入纯净阅读**：双击正文空白处（段落空白、行边距、正文下方）切换纯净阅读；双击在词上仍是选词，互不干扰。F11、右上角按钮与 Esc 退出照旧。

## 右键菜单

- **页签栏空白处右键**：打开新浏览器标签页 / 全部关闭。
- **网页内右键**：复制 / 粘贴 / 刷新——原生菜单弹在网页里，替换 Electron 默认的英文菜单。
- **主题按钮右键**：弹出完整主题列表（带色板与当前勾选），暖纸、石墨、纯黑这些扩展配色不用再绕去设置页；左键仍是三档快切。
