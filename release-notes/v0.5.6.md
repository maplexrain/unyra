归一 Unyra v0.5.6 —— 番茄钟迎来严格专注模式：守卫 agent 每分钟看一眼屏幕与摄像头，判离开自动暂停、分心弹窗与系统通知、隐私画面立即熔断；每次专注收场落一份报告，在资源管理器里回看。

## 严格专注（守卫 agent）

- **勾选监控即开启**：顶栏番茄钟的 tip 里新增「严格专注」——勾选「监控屏幕」「监控摄像头」（单选、全选皆可），勾选当场起媒体流并在 tip 里给实时画面，对着它把角度调好、确认没拍到不该拍的东西再开始。当前模型不支持看图会提前提示。
- **守卫每分钟看一眼**：守卫 agent（独立上下文，不属于导师）按勾选抽帧（屏幕 800px / 摄像头 480px），带现场说明发给模型，只回一个 JSON 判定。策略按能看到的画面自动调整：只开摄像头时只判人在不在；只开屏幕时用「距上次交互」当「人不在」的代理；「在学没在学」只有看得到屏幕才有发言权。
- **人不在 → 自动暂停**：摄像头看不到你（或只开屏幕时长时间没有交互）就暂停计时与监控，回到应用随便点一下、敲个键就恢复——计时接着走，监控等满一分钟再检查（刚坐回来那会儿不抢拍）。
- **分心 → 双路警告**：人在但屏幕内容与学习无关时，应用内弹窗与**系统通知**一起来（通知点一下把窗口叫回前台）；同一条警告有 60 秒冷却，误判可直接忽略。
- **隐私 → 立即熔断**：画面涉及隐私底线（走光、更衣、私密行为等）立即停掉全部媒体流、结束本次专注并弹窗说明。帧只活在内存里、从不落盘；会话收掉媒体流即断。
- **守卫上下文页签**：守卫在后台照常跑，打开它的页签可以把系统提示词、每轮真正发给模型的图像、模型的思考与回复原文、判定与动作全部摊开看。

## 专注模式报告

- 正常跑完、开始三分钟后停止、熔断，各落一份报告：完成组数、暂停次数与时长、分心警告、守卫逐轮判定、熔断原因一目了然。
- 资源管理器新增「专注报告」分类夹（写完即时刷新），点开是只读页签；切换页签时的自动定位也认它。

## 修复

- **守卫的缓存命中率**：模型历史改为纯文本（图像只挂当前轮消息）——图像进前缀会让不少服务商的前缀缓存整段永远命不中，且每轮请求重传全部历史帧；系统提示词充实成完整判据手册，第一轮就跨过服务商的最低缓存门槛；补上个别网关混用的 Anthropic 风格用量字段（此前命中被显示成 0%）。
- **dev 实例的系统通知**：未打包时 Windows 会静默丢弃 toast 通知（AppUserModelID 未注册）——改走托盘气泡，dev 与安装版都会亮。
- 单轮输出预算放宽（2048）：推理模型的思考不再把判定烧成空回复。
