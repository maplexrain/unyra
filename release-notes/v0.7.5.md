归一 Unyra v0.7.5 —— 节点宇宙灵动顶部工具条与完整标题悬浮、全局拓扑松弛自动排列算法、动态致谢赞助生态与发光赞赏码、考试窗口稳定直达与构建防锁强化。

## 节点宇宙：灵动工具栏与沉浸式阅读交互

- **顶部灵动工具栏（Palette）重构**：
  - 节点列表卡从左侧移至顶部水平居中，与左上角缩略图分离，释放左侧画布可视空间；
  - 采用直角微质感极简设计，常态下仅显示各类型图标，无冗余文字干扰；
  - 鼠标悬停任意节点项时向下弹出微质感 Tip，清晰呈现节点类型（文档、大纲、笔记、试卷、超级文档、视频、项目）；
- **节点标题完整悬停（Title）提示**：
  - 卡片顶部标题行容器与文本均赋予 `title` 原生属性，彻底根除知识图谱中长标题被 `...` 截断而无法辨认的痛点；
  - 大纲节点各目标项（Slots）与各类节点副标题全面补齐完整悬浮提示；
- **纯净阅读入口极简无框化**：
  - 节点宇宙（大纲页）右上角的纯净阅读按钮彻底去除外边框、背景色与阴影，只保留纯粹的 SVG 图标，视觉更沉浸。

## 画布拓扑：全局松弛自动排列算法

- **根除深层节点错位**：
  - 将画布自动排版的深度计算由局部单向遍历升级为全局拓扑排序松弛（Topological Relaxation）算法；
  - 彻底解决菱形接口子文档跨层排列时深度为 5、6 的节点意外被压缩至浅层 3、4 的错层排列 Bug，排版层次条理分明。

## 独立开发：动态致谢赞助生态与发光赞赏码

- **顶栏赞助入口与光晕赞赏码**：
  - 顶栏新增赞助入口按钮，悬停展开克制、得体的真诚浮层，支持带有金色/暖朱砂柔和呼吸发光效果的赞赏码；
  - 浮层文案诚挚自然，适可而止，杜绝卖惨与焦虑，真诚连接用户与作者；
- **赞助名单动态依赖与应用内直达**：
  - 将致谢名单从打包捆绑中解耦，收敛至项目仓库 `docs/sponsors.md`，并在 README 中提供持久链接；
  - 应用内新增 `sponsors` 只读页签，通过主进程网络通道多源动态同步仓库最新名单，更新名单无需重新发版客户端；
  - 兼具本地缓存秒开、离线兜底、手动刷新与一键导出 Markdown 能力。

## 系统稳定性：考试窗口与构建健壮性强化

- **考试答卷窗口卡死修复**：
  - 修复打开试卷时因真实 `mainWindow` 未正确绑定、就绪状态未同步及信号重发缺失导致的答卷窗口持续停留在“正在打开试卷”或白屏卡死的严重缺陷；
- **Windows 构建工具链防锁**：
  - 修复 Electron 编译阶段因预编译二进制文件（如 `screenHelper.exe`）被占用产生的 `EPERM: operation not permitted` 报错；
  - 为 `screenHelper` 增加标准输入 EOF 自动退出保护，杜绝后台游离进程。
