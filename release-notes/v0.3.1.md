归一 Guiyi v0.3.1 —— 超级导师学会了两种新本事：把可交互的「超级文档」直接生成在知识点上，把常用逻辑存成可复用的函数；表单提问改成一题一题来、答不答都随你。另有一批界面打磨与两个重要修复。

## 新增

- **超级文档**：超级导师可以为某个知识点生成「可交互的 HTML 文档」——自动出题的小工具、统计与自查的交互件、抽问卡片……在文档区右侧悬浮组的「超级文档」入口里打开，也可以删除。
  文档配色**实时跟随应用主题**：切浅色 / 深色 / 各彩色的瞬间，开着的超级文档立即跟着换装。
  里面的脚本跑在沙箱里，只能通过导师预先写好的函数取数，碰不到你的其他数据。
- **持久化函数**：导师可以把常用的逻辑（比如「统计某篇文档的句号」）存成带名字的函数，
  在编排里、也在超级文档的按钮里反复调用——写一次，处处复用，跨对话长期有效。
- **对话状态条**：输入框底部新增一行小字——聊了多少轮、干了多少步、模型此刻的输出速度（实时）、这个对话累计消耗的 token。
- **「节点文档」返回按钮**：在看笔记或超级文档时，悬浮组顶部会出现一颗按钮，一键回到该知识点的教学文档。
- **页签类型图标**：页签左侧现在有类型标识——教学文档（蓝）/ 笔记（琥珀）/ 超级文档（紫）/ 外部文件（灰），颜色固定不随主题变，一眼分清一排页签。

## 变更

- **表单提问一题一题来**：不再一次性铺开所有问题，答完一题（单选选中即自动到下一题）再翻页，随时可以退回去改；
  **所有题目都不再强制必答**——懒得答的留空直接提交就行，导师不会追问。
- 页签栏打磨：选中的页签与正文融为一体（脚下那条线被它接住）；右侧「源码 / 预览 / 导出」按钮组去掉外框，
  只在选中时点亮；导出图标重绘（箭头向上离开，不再像下载）。
- 标题大纲栏收起后只剩一颗安静的按钮，不再是一小块卡片壳。
- 顶栏更干净：去掉了标志、「已掌握 x/y」与学习状态徽标（这些在侧栏与状态面板里仍然看得到）。
- 超级文档的排版规范：按文档流整洁排版，不再生成一层套一层的圆角卡片。

## 修复

- **超级文档与持久化函数此前不会保存**：重启后就消失了。现在完整地随学习数据落盘、重启照旧。
- 对话进行中偶尔显示出天文数字的「输出速度」：已改为最近几秒的滚动窗口计算，并对不合理的数值直接丢弃。
- 升级无感，不碰任何学习数据，也不需要重新激活；安装包没有代码签名，Windows 提示「未知发布者」时点「更多信息 → 仍要运行」即可。
