归一 Unyra v0.5.4 —— 源码编辑器重做为 CodeMirror 6（符号自动补全、自动缩进），资源管理器全面支持拖拽，试卷支持带图题并自带视觉自检。

## 源码编辑器

- **编辑模式换用 CodeMirror 6**：按文件后缀的语法高亮（Markdown、JS/TS、Python、CSS 等常见后缀都认），完全本地运行，不依赖任何在线服务。
- **符号自动补全**：括号、引号自动闭合；**自动缩进**：换行跟上层级，Tab 直接缩进。
- 修复 Markdown 编辑一换行就弹回原状的问题；修复切换页签时编辑区整页重渲、内容没正常载入的问题。
- 编辑区的上边距降到与左右同一尺度，首行不再被右上角的悬浮按钮压住。

## 资源管理器

- **收藏分组**：可以新建分组、给分组改名、把收藏拖进分组归类；组内收藏缩进显示，整理动作全部收进右键菜单（列表右侧有「新建分组」按钮）。
- **收藏项可拖拽**：拖到文档区直接打开，拖进对话输入框变成引用 chip，拖到分组上完成归类。
- **工作区文件拖拽**：文件 / 文件夹拖到目录上即移动，按住 Ctrl 拖是复制；拖拽打开的范围扩大到整个文档区，不必瞄准某一行。
- **多媒体预览**：图片、音频、视频文件可以开独立的预览页签；文本文件按后缀直接打开（Markdown 照旧进预览，空 Markdown 直接进编辑）。
- 鼠标经过本地文件项与收藏项不再抖动（行内按钮收进右键菜单，行高不再跳）。

## 试卷

- **带图题**：导师出题时可以用 SVG 画几何图、函数图像、受力示意这类图形作为题目配图；配图随试卷一起保存，作答与复盘页签里都能看到。
- **插图视觉自检**：出完卷自动把每张配图渲染成位图、交给视觉模型检查「渲染是否正常、与题干是否相符」，发现坏图自动重画修复。
- **数学公式硬规矩**：题面涉及公式一律按 LaTeX 渲染（行内 $…$、独立 $$…$$），不再出现「x²」这类纯文本近似。

## 可靠性

- **state.json 原子写入**：修掉「文件写到一半、下次启动按空库处理、再保存时把收藏 / 对话 / 页签布局永久覆盖」的根因。如果你的收藏曾经莫名消失，这个版本是答案。
- 修复试卷 chip 点击后打不开的问题。

## 文档区

- 右上角的大纲按钮改为只在预览模式出现（大纲是从渲染后的正文里抽出来的）。
- 函数图像（```plot）渲染后的边框去掉。
