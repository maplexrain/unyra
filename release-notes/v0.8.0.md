归一 Unyra v0.8.0 —— 全局 Vim 命令与拼音检索中心、全新纯净阅读模式、Typst 出版级排版渲染引擎、笔记多源码格式支持、分栏微光联动高亮与机考判分引擎修复。

## 全局 Vim 命令与快捷检索中心

- **无遮罩轻量命令栏**：
  - 全新重构全局 Vim 命令输入框，采用精致毛玻璃质感与立体微投影设计，完全移除全屏暗色遮罩与模糊层，输入命令时不遮挡正文与视口内容；
  - 非模态轻量体验：按下 `:` 即时唤起，执行确认后立即响应收起，点击任意外部区域自然退出演示，不阻塞页面交互。
- **`:open` 全场景拼音检索**：
  - 新增 `:open`（或 `:o`）命令，弹出专属快捷导航面板；
  - 支持对教学文档、大纲导读、笔记、机考记录、超级文档、视频、本地文件、工作区代码、设置页签与用量页签进行一站式打开；
  - 集成全拼与首字母缩写拼音快速匹配，每项均展示专属类型图标与分类徽章。
- **丰富 Vim Ex 命令扩充**：
  - `:edit`：当前页面若支持编辑，一键从浏览模式无缝转为编辑模式；
  - `:view` / `:read` / `:browse` / `:noedit`：当前页面一键由源码编辑切回文档预览模式；
  - `:browser [url]`：在工作区快速新建内置浏览器页签，可选携带初始网址；
  - `:fullscreen` / `:exitfullscreen`：快捷进入或退出沉浸式阅读；
  - `:wrap` / `:nowrap`（兼容 `:set wrap` / `:set nowrap`）：自由切换编辑器自动换行与单行水平滚动。
- **键盘导航与快捷体验**：
  - 命令候选列表全面支持 <kbd>Ctrl+J</kbd> / <kbd>Ctrl+K</kbd> 及方向键快速循环切换，选中的选项自动平滑滚入可视区；
  - 建立权威唯一真实来源（`vimCommandCatalog.ts`），命令定义与速查文档（Cheat Sheet）一体化联动。

## 全新重做纯净阅读模式（Zen Mode）

- **沉浸式结构重构**：
  - 纯净阅读模式全新演进：保留顶部页签栏与主页面主体，隐藏侧边栏与冗余浮动控件；
  - 展开与收起全程搭载平滑流畅的尺寸缩放与淡入淡出过渡动画；
  - 纯净模式切换入口置顶于左侧悬浮工具条（DocFloat）首位，随时一键切换沉浸专注状态。

## Typst 出版级排版支持与笔记多源码格式

- **原生 Typst 解析与预览引擎**：
  - 深度支持 Typst 现代排版语法，支持 `#set document`、`#set page`、`#set text`、`#set heading`、`#set par` 等核心指令；
  - 支持 `#align(...)`、`#block(...)`、`#table(...)` 等结构化函数块，呈现出版级文档排版；
  - 数学公式解析引擎优化，彻底消除包含中文字符时的控制台警报，提升公式渲染健壮性。
- **笔记源码类型自由切换**：
  - 笔记支持在普通文本（Plain Text）、Markdown、HTML 与 Typst 之间自由切换源码类型；
  - 左侧按钮组提供直观类型切换入口，鼠标悬停提供详细提示说明，并支持将指定格式设为全局默认格式。

## 编辑器分栏预览与光标微光联动

- **光标位置元素微光高亮**：
  - 编辑器双栏实时预览支持精准光标联动：光标在源码区移动时，右侧预览中对应的标题、段落、列表或引用块自动高亮微光背景并轻柔同步视口。
- **单行水平滚动优化**：
  - 编辑区域源码默认单行水平滚动、不再强制换行，长代码与公式排版更为清晰整洁，可随时通过 `:wrap` 命令开启换行。

## 能力接入设置重构与机考判分引擎修复

- **模型能力接入 UI 升级**：
  - 重塑模型配置中心中的「能力接入」（TTS 语音合成 / STT 语音识别 / OCR 文字识别 / 云端文件）面板布局，大幅提升空间利用率与现代视觉质感；
  - 插件配置明确标注 Beta 阶段与支持完善中提示。
- **机考作答判定修复**：
  - 彻底修复非手写机考模式下用户真实作答偶发被篡改导致客观题判定为全错（0/N）的关键 Bug；
  - 统一答题卡快速判分、客观题判定逻辑与 AI 导师深度诊断流，确保判分与解析严密一致。
