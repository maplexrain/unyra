归一 Unyra v0.7.10 —— 参数化可交互教学仿真卡片（```pisc 围栏组件）、Agent 系统提示词全学科教学泛化、视频倍速菜单交互优化、节点宇宙标题排版与尺寸体验升级。

## 通用参数化可交互教学仿真卡片（```pisc）

- **全新内置代码块围栏组件（```pisc）**：
  - 在教学文档与笔记中支持插入原生参数化可交互仿真画布组件；
  - 支持在围栏首行直接声明卡片标题（如 ```` ```pisc 简谐振动受迫共振动态模拟 ````），在卡片顶部实时展示标题并注入 Canvas 实例。
- **Canvas 独立沙盒执行与事件交互**：
  - 渲染时为每个卡片实例化一个名为 `card` 的 `HTMLCanvasElement` 传入执行沙盒，只允许在 Canvas 内部通过 2D API 绘图与监听鼠标/触控交互；
  - 便捷辅助方法：提供 `card.getPointerPos(e)` 精准换算画布相对坐标、`card.isDark` 自动感知深浅色主题、`card.cardTitle` 读取卡片标题；
  - 完善的生命周期管理：自动追踪注销 `requestAnimationFrame`、定时器与事件监听器，提供一键重置与异常优雅降级展示。
- **双重安全沙盒防护**：
  - 静态关键字拦截：严格阻止 `window`、`document`、`globalThis`、`parent`、`top`、`fetch`、`XMLHttpRequest`、`WebSocket`、`Worker`、`localStorage`、`sessionStorage`、`cookie`、`process`、`require`、`eval`、`Function` 等全局对象与网络/存储 API；
  - 运行时形参遮蔽：在沙盒中将危险全局变量绑定为 `undefined`，杜绝恶意脚本越界。
- **现代纯直角与无 Emoji 设计规范**：
  - 卡片容器、舞台、画布与按钮均严格采用无圆角（`border-radius: 0`）极简直角工程设计语言，与文档中现有的引用块（`quote`）及问答卡片（`aiqa`）视觉调性深度契合；
  - 界面全面去 Emoji 化，统一使用细腻的 SVG 矢量图标；
  - 极简重置操作：重置按钮移除外边框、背景底色与文字标签，采用纯 SVG 旋转重置图标。
- **全学科交互教学场景泛化**：
  - 物理与工程科学：动力学轨道、带电粒子偏转、波动干涉、热力学分子运动、RLC电路阻尼、PID控制回路响应；
  - 计算机科学与软件工程：算法执行演化（排序/最短路径/A*寻路/动态规划）、核心数据结构操作（二叉树旋转/堆调整/哈希冲突）、操作系统内存分页置换、网络协议与状态机；
  - 数理统计与几何：微积分极限与导数切线逼近、矩阵线性变换网格拉伸、概率分布与马尔可夫链、梯度下降极值优化；
  - 生物学与生态演化：种群竞争与捕食者周期（Lotka-Volterra）、遗传学性状分离、神经元动作电位脉冲触发；
  - 经济学与社会博弈：市场供求曲线动态均衡、囚徒困境演化博弈；
  - 通用概念实验台：任何需要让学习者“调一调参数、拖一拖节点、直观看到反馈”以打破抽象认知墙的知识场景。

## 智能导师 Agent 系统提示词升级

- **注入 PISC 交互仿真指南**：
  - 在核心不可变系统提示词规范（`buildTeacherSystem`）中注入 `PISC_SYNTAX_GUIDE`；
  - 引导导师在讲解物理过程、数学几何变换、算法演进与系统控制等需要直观动手探究的知识节点时，主动编写高质量的参数化动态仿真卡片。

## 视频播放与节点宇宙交互体验优化

- **重做倍速播放菜单交互与层级**：
  - 视频播放器倍速选项菜单改为点击固定打开，选择倍速后或点击空白处关闭，彻底解决鼠标滑过容易失焦误关的问题；
  - 优化浮层 z-index 层级，避免与其他控件冲突。
- **拓扑图节点标题展示优化**：
  - 节点宇宙画布中节点标题由单行截断改为最多展示两行，超出自动省略，容纳更多概念信息。
- **节点宇宙顶部菜单放大**：
  - 增大节点宇宙顶部核心菜单尺寸与点击热区，提高操作易用性。
- **去除画布节点入口标识**：
  - 移除画布节点原本冗余的入口角标，使整张知识图谱拓扑更加轻快清爽。
